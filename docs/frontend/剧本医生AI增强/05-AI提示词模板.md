## 诊断任务

请作为专业的短剧编剧顾问，从以下8个维度对本剧本的前期准备进行深度诊断：

### 1. 世界观自洽性分析（满分10分）
- 时间线/空间设定是否存在矛盾
- 世界观规则是否前后一致
- 背景设定的独特性评价
- 与剧本类型的契合度

### 2. 角色立体度评估（满分10分）
- 每个角色的性格是否鲜明、有辨识度
- 背景故事能否支撑角色的行为动机
- 主角是否有清晰的成长空间
- 配角是否避免工具人化

### 3. 角色关系张力分析（满分10分）
- 关系网络的冲突张力强度（1-10分）
- 关系设定的合理性与发展潜力
- 最有化学反应的CP组合建议
- 关系弧线的预期走向

### 4. 大纲逻辑合理性（满分10分）
- 三幕结构的节奏是否符合短剧特点（快节奏、强冲突）
- 关键节点设置是否合理（开端/转折/高潮/结局）
- 情感线和剧情线是否交织得当
- 是否有足够的反转和爽点

### 5. 剧情完整性评估（满分10分）
- 节点覆盖是否完整（无明显断层）
- 每幕节点数量是否合理
- 集数规划是否与内容量匹配
- 主要角色在大纲中的出场频率

### 6. 情感浓度预测（满分10分）
- 情感关键词的丰富度
- 预期的情感曲线走向
- 甜/虐/爽点的分布合理性
- 观众共鸣点的设置

### 7. 商业价值预判（满分10分）
- 题材的市场热度分析
- 与当前流行趋势的契合度
- 爆款要素的覆盖度（反转/金句/话题点）
- 潜在观众群体画像

### 8. 创作就绪度（满分10分）
- 基础设定的完整程度
- 是否具备开始分集创作的条件
- 最紧迫需要解决的问题（TOP 3）
- 整体质量预期

## 🔧 代码实现示例

### 提示词生成函数

```javascript
/**
 * 生成前期准备诊断提示词
 */
function generatePreparationDiagnosisPrompt(project) {
  // 基础信息
  const projectName = project.name || '未命名项目';
  const projectType = project.type || '未指定';
  const episodeCount = project.episodeCount || 60;
  
  // 世界观摘要
  const worldview = project.worldview || {};
  
  // 角色信息
  const characters = project.characters || [];
  const charactersSummary = characters.map((char, index) => {
    return `### ${index + 1}. ${char.name}（${char.role || '角色'}）
- 年龄：${char.age || '未设置'}
- 性别：${char.gender || '未设置'}
- 描述：${char.description || '无'}
- 性格：${char.personality || '无'}
- 背景：${char.background || '无'}
- 动机：${char.motivation || '无'}`;
  }).join('\n\n');
  
  // 关系图谱
  const relationships = project.relationships || [];
  const relationshipsSummary = relationships.map(rel => {
    const dir = rel.direction === 'bidirectional' ? '↔' : '→';
    return `- ${rel.from} ${dir} ${rel.to}：${rel.type}（${rel.direction}，强度${rel.strength}星）
  ${rel.description || ''}`;
  }).join('\n');
  
  // 大纲信息
  const acts = project.outline?.acts || [];
  const actsSummary = acts.map((act, actIndex) => {
    const plotPoints = act.plotPoints || [];
    const nodesSummary = plotPoints.map((node, nodeIndex) => {
      return `${nodeIndex + 1}. ${node.name}（预计第${node.episodeRange || '未定'}集）
   - 描述：${node.description || '无'}
   - 涉及角色：${Array.isArray(node.characters) ? node.characters.join('、') : '无'}
   - 情感：${Array.isArray(node.emotion) ? node.emotion.join('、') : '无'}`;
    }).join('\n');
    
    return `### 第${actIndex + 1}幕：${act.title}
**幕描述**：${act.description || '无'}

**关键节点**：
${nodesSummary}`;
  }).join('\n\n');
  
  // 组装完整提示词（使用模板）
  return `# 短剧剧本前期准备深度诊断任务

## 项目基本信息
- 剧本名称：${projectName}
- 剧本类型：${projectType}
- 目标集数：${episodeCount}集
- 每集时长：2-3分钟

---

## 世界观设定

### 故事背景
${worldview.background || '未设置'}

### 世界设定
${worldview.setting || '未设置'}

### 核心主题
${worldview.theme || '未设置'}

### 主要冲突
${worldview.conflict || '未设置'}

### 情感基调
${worldview.tone || '未设置'}

---

## 角色设定（共${characters.length}个）

${charactersSummary || '暂无角色'}

---

## 角色关系图谱（共${relationships.length}条）

${relationshipsSummary || '暂无关系'}

---

## 剧情大纲（三幕结构）

${actsSummary || '暂无大纲'}

---

[... 后续任务说明与输出格式要求 ...]
`;
}
```

## 📝 使用说明

### 步骤1：生成提示词
```javascript
const prompt = generatePreparationDiagnosisPrompt(project);
```

### 步骤2：调用外部AI
将生成的提示词复制到：
- ChatGPT（GPT-4或GPT-3.5）
- Claude（Claude 2或3）
- 文心一言
- 通义千问
- 讯飞星火

### 步骤3：获取结果
AI会按照格式返回结构化的诊断报告

### 步骤4：解析展示（可选）
```javascript
const result = parseAIDiagnosisResponse(aiResponse);
displayDiagnosisResult(result);
```

## 🔄 提示词优化建议

### 根据实际使用调整

1. **如果AI回答过于简短**
   - 在任务说明中强调"详细"、"具体"
   - 增加示例答案长度

2. **如果AI不遵守格式**
   - 强化"⚠️ 重要"部分的说明
   - 在开头就给出格式要求

3. **如果评分不够准确**
   - 增加每个维度的评分标准细节
   - 给出评分参考案例

4. **如果建议不够可执行**
   - 要求建议必须包含"位置"和"具体改法"
   - 增加"预期效果"字段
