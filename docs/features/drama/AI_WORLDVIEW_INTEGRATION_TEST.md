# 世界观AI自动生成功能测试指南

## 📋 功能概述

在【世界观设定】模块新增了AI自动生成功能，用户可以：
1. ✨ **一键AI生成** - 自动生成并填充世界观设定
2. ⏳ **流式生成** - 实时看到AI生成过程
3. 📝 **手动模式** - 保留原有的提示词生成功能

---

## 🚀 快速开始

### 前置条件

1. **后端运行正常**
   ```bash
   cd backend
   npm run dev
   ```

2. **前端运行正常**
   ```bash
   cd frontend
   npm run dev
   ```

3. **配置AI连接（二选一）**
   - 方式1：用户在【个人中心】配置自己的AI密钥（BYOK）
   - 方式2：管理员配置平台AI服务

---

## 🧪 测试场景

### 场景1：用户已配置AI密钥

#### 步骤：
1. 登录系统
2. 前往【个人中心】→【AI配置】
3. 添加AI连接（如OpenAI、DeepSeek等）
4. 前往【AI短剧剧本生成器】
5. 创建新项目或打开已有项目
6. 进入【世界观设定】标签页
7. 点击"AI自动生成"按钮

#### 预期结果：
- ✅ 显示"AI正在生成世界观设定..."提示
- ✅ 显示进度条（0% → 100%）
- ✅ 生成完成后自动填充到表单各字段
- ✅ 显示成功提示："AI生成成功，已自动填充到表单"
- ✅ 表单数据可以正常保存

---

### 场景2：用户未配置AI密钥

#### 步骤：
1. 登录系统（但未配置AI密钥）
2. 前往【世界观设定】
3. 点击"AI自动生成"按钮

#### 预期结果：
- ✅ 显示提示框："未找到可用的AI连接..."
- ✅ 提供三个选项：
  - "去配置" - 跳转到AI配置页面
  - "手动模式" - 切换到生成提示词
  - "取消" - 关闭提示
- ✅ 点击"去配置"打开新标签页到AI配置页面
- ✅ 点击"手动模式"显示提示词对话框

---

### 场景3：流式生成模式

#### 步骤：
1. 确保已配置AI密钥
2. 前往【世界观设定】
3. 点击"AI自动生成"下拉箭头
4. 选择"流式生成（实时显示）"

#### 预期结果：
- ✅ 显示"AI正在生成世界观设定..."提示
- ✅ 在提示框中实时显示生成的内容（流式输出）
- ✅ 内容完整生成后自动填充到表单
- ✅ 显示成功提示

---

### 场景4：部分填写后生成

#### 步骤：
1. 手动填写部分内容，如：
   - 背景："现代都市"
   - 主题："爱情与成长"
2. 点击"AI自动生成"

#### 预期结果：
- ✅ AI根据已填写内容生成更符合预期的设定
- ✅ 保留用户已填写的内容（或基于此扩展）
- ✅ 生成质量更高、更贴合用户意图

---

### 场景5：空白状态生成

#### 步骤：
1. 不填写任何内容
2. 点击"AI自动生成"

#### 预期结果：
- ✅ 显示提示："建议先填写部分世界观内容..."
- ✅ 提供"继续生成"和"去填写"两个选项
- ✅ 点击"继续生成"正常生成
- ✅ 点击"去填写"取消操作

---

### 场景6：手动模式（保留功能）

#### 步骤：
1. 点击"AI自动生成"下拉箭头
2. 选择"生成提示词（手动）"

#### 预期结果：
- ✅ 显示提示词对话框
- ✅ 可以复制提示词
- ✅ 与原有功能一致，无破坏性变更

## 🐛 常见问题排查

### 问题1：点击按钮无反应

**可能原因：**
- 前端API模块导入错误
- request工具路径不对

**解决方案：**
```bash
# 检查控制台错误
# 确认 @/utils/request 路径正确
# 确认 @/api/ai 文件存在
```

---

### 问题2：提示"未找到可用的AI连接"

**可能原因：**
- 用户未配置AI密钥
- 平台未配置AI服务
- 后端服务未启动

**解决方案：**
1. 检查后端服务：`http://localhost:3000/api/ai/connections`
2. 配置用户AI密钥或平台AI服务
3. 检查后端日志

---

### 问题3：生成内容无法填充

**可能原因：**
- AI返回格式不正确
- 解析器逻辑问题

**解决方案：**
1. 查看控制台AI返回内容
2. 检查 `parseWorldviewResponse` 函数
3. 调整提示词格式要求

---

### 问题4：流式生成不显示

**可能原因：**
- SSE实现问题
- 后端未返回正确格式

**解决方案：**
1. 检查Network中SSE连接
2. 确认后端返回 `data: {...}` 格式
3. 检查浏览器兼容性
