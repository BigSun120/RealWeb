# AI短剧脚本生成器 - 快速启动指南

## 🚀 快速开始

### 1. 启动开发服务器

```bash
cd E:\AI\mycode\RealWeb

# 启动前端开发服务器
cd frontend
npm run dev

# 如果需要后端（目前前端使用Mock数据，后端可选）
cd ../backend
npm run dev
```

### 2. 访问工具

#### 方式一：从工具箱进入
1. 打开浏览器访问: `http://localhost:5173/tools`
2. 找到"AI短剧剧本生成器"工具卡片（带🎬图标）
3. 点击工具卡片进入

#### 方式二：直接访问
直接访问: `http://localhost:5173/tools/productivity/drama-script-generator`

### 3. 登录要求

⚠️ **注意**: 该工具需要登录才能访问

- 如果未登录，会自动跳转到登录页
- 登录后会自动返回工具页面

## 🔍 调试技巧

### 浏览器开发者工具
1. 打开控制台 (F12)
2. 查看 Console 标签页的日志输出
3. 检查 Network 标签页的请求（后续接入API后）
4. 使用 Vue DevTools 查看组件状态

### 常见问题排查

#### 1. 页面无法访问
- 检查开发服务器是否启动
- 检查端口是否被占用
- 查看控制台错误信息

#### 2. 未登录跳转
- 正常行为，工具需要登录
- 使用测试账号登录
- 或临时修改路由配置去除 `requiresAuth`

#### 3. 组件显示异常
- 清除浏览器缓存
- 重启开发服务器
- 检查 Element Plus 是否正确导入
