# 全部令牌管理功能开发需求文档

## 一、文档概述

- **文档版本**：1.0
- **创建日期**：2024年12月
- **适用范围**：Augment Token Manager Web版
- **开发目标**：为管理员提供全局令牌管理功能

## 二、功能概述

### 2.1 功能定位
为系统管理员提供一个统一的令牌管理界面，能够查看、管理系统中所有用户的所有令牌，包括个人令牌和令牌池中的令牌。

### 2.2 核心价值
- **全局视图**：管理员可以从全局角度管理所有令牌
- **数据一致性**：确保不同数据源的令牌状态保持同步
- **批量操作**：提高管理效率，支持批量处理令牌
- **权限控制**：严格的管理员权限验证

## 四、数据架构设计

### 4.1 数据来源
系统需要聚合以下数据源的令牌信息：

1. **个人令牌表 (AugmentToken)**
   - 所有用户的个人令牌
   - 包含用户关联信息
   - 状态：活跃/禁用

2. **令牌池表 (TokenPool)**
   - 共享令牌池中的令牌
   - 包含上传者和领取者信息
   - 状态：可用/已领取/过期/无效

## 六、核心功能详细设计

### 6.1 强制刷新Portal信息
**功能描述**：批量刷新选中令牌的Portal信息和状态

**实现方案**：
- 使用进度条展示刷新进度
- 每完成一个令牌刷新，进度条前进
- 支持并发控制，避免API限流
- 实时更新表格数据

```javascript
const batchRefreshPortal = async () => {
  const totalTokens = selectedTokens.value.length
  let completedCount = 0
  
  // 显示进度条
  refreshProgress.value = {
    visible: true,
    current: 0,
    total: totalTokens,
    status: 'active'
  }
  
  // 并发控制，每次处理2个
  const concurrency = 2
  for (let i = 0; i < totalTokens; i += concurrency) {
    const batch = selectedTokens.value.slice(i, i + concurrency)
    const promises = batch.map(async (token) => {
      try {
        const result = await adminTokenService.refreshPortalInfo(token.id)
        // 更新本地数据
        updateTokenInList(token.id, result.data)
        return { success: true, tokenId: token.id }
      } catch (error) {
        return { success: false, tokenId: token.id, error: error.message }
      }
    })
    
    const results = await Promise.all(promises)
    completedCount += results.length
    
    // 更新进度条
    refreshProgress.value.current = completedCount
  }
  
  // 完成后隐藏进度条
  refreshProgress.value.visible = false
}
```

### 6.2 转移所有权

const transferOwnership = async (targetUserId, targetUsername) => {
  try {

### 6.3 强制回收到池
**功能描述**：将个人令牌强制回收到令牌池

**实现方案**：
- 验证令牌有效性
- 创建令牌池记录
- 删除个人令牌记录
- 更新令牌状态为池中可用

```javascript
const batchReclaim = async () => {
  try {
    const personalTokens = selectedTokens.value.filter(t => t.source === 'personal')
    if (personalTokens.length === 0) {
      ElMessage.warning('请选择个人令牌进行回收')
      return
    }

    const result = await adminTokenService.batchReclaimToPool({
      tokenIds: personalTokens.map(t => t.id)
    })

    // 更新本地数据
    personalTokens.forEach(token => {
      token.source = 'pool'
      token.tokenStatus = 'pool_available'
      token.ownerInfo = null
    })

    ElMessage.success(`成功回收 ${result.successCount} 个令牌到池中`)
  } catch (error) {
    ElMessage.error(`回收失败: ${error.message}`)
  }
}
```

### 6.4 禁用/启用令牌
**功能描述**：批量禁用或启用令牌使用

**实现方案**：
- 切换令牌的 isActive 状态
- 更新数据库记录
- 实时更新界面显示

```javascript
const batchToggleStatus = async () => {
  try {
    const tokenIds = selectedTokens.value.map(t => t.id)
    const hasActiveTokens = selectedTokens.value.some(t => t.isActive)
    const action = hasActiveTokens ? 'disable' : 'enable'

    const result = await adminTokenService.batchToggleStatus({
      tokenIds,
      action
    })

    // 更新本地数据
    selectedTokens.value.forEach(token => {
      token.isActive = action === 'enable'
      token.tokenStatus = action === 'enable' ?
        (token.source === 'personal' ? 'personal' : 'pool_available') :
        'disabled'
    })

    ElMessage.success(`成功${action === 'enable' ? '启用' : '禁用'} ${result.successCount} 个令牌`)
  } catch (error) {
    ElMessage.error(`操作失败: ${error.message}`)
  }
}
```

### 6.5 批量删除令牌
**功能描述**：彻底删除选中的令牌

**实现方案**：
- 二次确认删除操作
- 同时删除个人令牌和令牌池记录
- 清理相关的状态记录
- 更新界面数据

```javascript
const batchDelete = async () => {
  try {
    await ElMessageBox.confirm(
      `确定要删除选中的 ${selectedTokens.value.length} 个令牌吗？此操作不可恢复！`,
      '确认删除',
      {
        type: 'warning',
        confirmButtonText: '确定删除',
        cancelButtonText: '取消'
      }
    )

    const tokenIds = selectedTokens.value.map(t => t.id)
    const result = await adminTokenService.batchDelete({ tokenIds })

    // 从本地数据中移除已删除的令牌
    const deletedIds = new Set(result.deletedIds)
    allTokens.value = allTokens.value.filter(token => !deletedIds.has(token.id))
    selectedTokens.value = []

    ElMessage.success(`成功删除 ${result.successCount} 个令牌`)
  } catch (error) {
    if (error !== 'cancel') {
      ElMessage.error(`删除失败: ${error.message}`)
    }
  }
}
```

## 八、数据一致性保证

### 8.1 数据同步策略
1. **统一数据访问层**：创建 AdminTokenService 统一处理所有令牌数据
2. **事务处理**：关键操作使用数据库事务确保一致性
3. **状态同步**：操作后及时同步相关表的状态信息
4. **缓存更新**：操作后清理相关缓存，确保数据实时性

### 8.2 数据验证机制
```javascript
// 数据一致性验证
const validateTokenConsistency = async (tokenId) => {
  const personalToken = await AugmentToken.findById(tokenId)
  const poolToken = await TokenPool.findOne({ accessToken: personalToken?.accessToken })
  const tokenStatus = await TokenStatus.findByAccessToken(personalToken?.accessToken)

  // 验证数据一致性
  if (personalToken && poolToken) {
    throw new Error('令牌同时存在于个人和池中，数据不一致')
  }

  // 更新状态记录
  if (tokenStatus) {
    await tokenStatus.syncWithCurrentState(personalToken || poolToken)
  }
}
```

## 九、进度条实现方案

### 9.1 进度条组件设计
```vue
<template>
  <el-dialog v-model="refreshProgress.visible" title="批量刷新Portal信息" :closable="false">
    <div class="progress-container">
      <el-progress
        :percentage="progressPercentage"
        :status="refreshProgress.status"
        :stroke-width="8"
        text-inside
      />
      <div class="progress-info">
        <p>正在刷新令牌Portal信息...</p>
        <p>进度: {{ refreshProgress.current }} / {{ refreshProgress.total }}</p>
        <div v-if="refreshProgress.errors.length > 0" class="error-list">
          <p>失败的令牌:</p>
          <ul>
            <li v-for="error in refreshProgress.errors" :key="error.tokenId">
              {{ error.emailNote }}: {{ error.error }}
            </li>
          </ul>
        </div>
      </div>
    </div>
  </el-dialog>
</template>

<script setup>
const refreshProgress = ref({
  visible: false,
  current: 0,
  total: 0,
  status: 'active', // active, success, exception
  errors: []
})

const progressPercentage = computed(() => {
  if (refreshProgress.value.total === 0) return 0
  return Math.round((refreshProgress.value.current / refreshProgress.value.total) * 100)
})
</script>
```

### 9.2 进度更新逻辑
```javascript
const updateProgress = (completed, total, errors = []) => {
  refreshProgress.value.current = completed
  refreshProgress.value.total = total
  refreshProgress.value.errors = errors

  if (completed === total) {
    refreshProgress.value.status = errors.length > 0 ? 'exception' : 'success'
    // 3秒后自动关闭
    setTimeout(() => {
      refreshProgress.value.visible = false
    }, 3000)
  }
}
```
