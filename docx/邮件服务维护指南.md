# 📧 邮件服务维护指南

## 🎯 服务概览

### 当前邮件系统架构
```
注册验证邮件：用户注册 → EmailService → Postfix → 用户真实邮箱
临时邮箱服务：外部邮件 → Postfix → 虚拟域名转发 → Inbucket
```

### 服务组件
- **Postfix**：主邮件服务器（端口25）
- **Inbucket**：临时邮箱服务（端口2500/9000）
- **EmailService**：后端邮件发送服务

## 🔧 服务管理命令

### Postfix 管理
```bash
# 检查状态
systemctl status postfix

# 启动/停止/重启
systemctl start postfix
systemctl stop postfix
systemctl restart postfix

# 检查配置
postfix check
postconf mydestination virtual_mailbox_domains virtual_transport

# 查看邮件队列
mailq

# 查看日志
tail -f /var/log/mail.log
```

### Inbucket 管理
```bash
# 检查容器状态
docker ps | grep inbucket

# 启动临时邮箱服务
docker run -d --name inbucket-temp \
  -p 9000:9000 -p 2500:2500 -p 1100:1100 \
  -e INBUCKET_SMTP_DOMAIN=godaug.fun,localhost,test.local \
  -e INBUCKET_SMTP_ADDR=0.0.0.0:2500 \
  -e INBUCKET_WEB_ADDR=0.0.0.0:9000 \
  -e INBUCKET_STORAGE_TYPE=memory \
  -e INBUCKET_STORAGE_RETENTIONPERIOD=24h \
  inbucket/inbucket:latest

# 停止/重启
docker stop inbucket-temp
docker restart inbucket-temp

# 查看日志
docker logs inbucket-temp
```

##  故障排除

### 常见问题

#### 1. 注册邮件发送失败
```bash
# 检查后端日志
pm2 logs website-backend

# 检查Postfix日志
tail -f /var/log/mail.log

# 测试SMTP连接
echo "test" | mail -s "test" your-email@gmail.com
```

#### 2. 临时邮箱接收失败
```bash
# 检查Postfix虚拟域名配置
postconf virtual_mailbox_domains virtual_transport

# 检查Inbucket状态
curl -s http://localhost:9000/
docker logs inbucket-temp

# 测试邮件转发
echo "test temp email" | mail -s "test" test@godaug.fun
```

#### 3. 端口冲突
```bash
# 检查端口占用
ss -tlnp | grep -E "(25|2500|9000)"

# 检查防火墙
iptables -L -n | grep -E "(25|2500|9000)"
```

### 错误代码说明
- **5.1.1 User unknown**：用户不存在，检查虚拟域名配置
- **5.7.1 Relay access denied**：中继被拒绝，检查mydestination配置
- **Connection refused**：服务未启动或端口被阻止
