# 02 - 阶段一：前期准备检查

## 🎯 阶段目标

确保在开始分集创作前，世界观、角色、关系、大纲的基础质量达标。

**通过标准**：≥75分可开始分集创作

---

## 📊 评分体系

### 总分构成（100分）

```
世界观完整性     20分  (20%)
角色设定质量     25分  (25%)
角色关系图谱     25分  (25%)
剧情大纲结构     30分  (30%)
────────────────────────
总分             100分
```

---

## 1️⃣ 世界观完整性（20分）

### 检查项

#### 字段完整度（10分）
- 故事背景：必填（2分）
- 世界设定：必填（2分）
- 核心主题：必填（2分）
- 主要冲突：必填（2分）
- 情感基调：必填（2分）

#### 内容充实度（6分）
- 背景/设定/冲突 ≥150字：各2分
- 主题 ≥60字：1分
- 基调 ≥20字：1分

#### 类型特征匹配（4分）
根据剧本类型检查关键词：
- 霸总类：豪门、契约、联姻、强强
- 甜宠类：校园、初恋、宠溺、双向
- 悬疑类：真相、线索、反转、揭秘
- 复仇类：仇恨、报复、身份、逆袭

### 问题等级

**严重（阻断）**：
- 必填字段缺失

**警告**：
- 字数不足建议值

**提示**：
- 缺少类型特征词

---

## 2️⃣ 角色设定质量（25分）

### 检查项

#### 角色数量配置（8分）
- 主角（男/女主）：1-2个（4分）
- 主要配角：2-4个（2分）
- 反派角色：1-2个（1分）
- 总数合理：4-8个（1分）

#### 单角色完整度（12分）
每个角色检查：
- 基础信息：姓名、年龄、性别、角色定位（3分）
- 性格描述：≥50字（3分）
- 角色背景：≥100字（3分）
- 行为动机：≥80字（3分）

#### 参与度检查（5分）
- 主角在大纲节点出现率 ≥70%（3分）
- 主要配角在大纲中有出现（2分）

### 问题等级

**严重**：
- 没有主角
- 角色名重复

**警告**：
- 性格/背景字数过少
- 角色未在大纲中出现

---

## 3️⃣ 角色关系图谱（25分）

### 检查项

#### 覆盖度（10分）
- 主角关系数 ≥4条（5分）
- 配角关系数 ≥2条（3分）
- 总关系数 ≥8条（2分）

#### 张力指数（10分）
- 存在冲突关系（竞争/仇恨/误会）：6分
- 关系强度分布合理（1-5星均有）：2分
- 关系类型多样（≥5种类型）：2分

#### 连通性（5分）
- 无孤立节点：3分
- 主角为关系中心：2分

### 问题等级

**严重**：
- 主角无任何关系连接

**警告**：
- 关系覆盖不足
- 缺少冲突型关系

**提示**：
- 建议增加某类关系

---

## 4️⃣ 剧情大纲结构（30分）

### 检查项

#### 三幕均衡度（12分）
- 第一幕：3-5个节点（4分）
- 第二幕：5-7个节点（4分）
- 第三幕：3-5个节点（4分）

#### 节点质量（12分）
每个节点检查：
- 名称具体（非空泛）：3分
- 描述充实 ≥50字：3分
- 涉及角色明确：3分
- 情感/集数完整：3分

#### 集数规划（6分）
- 覆盖1到目标集数：3分
- 无大段空档（>10集）：2分
- 节点分布均匀：1分

### 问题等级

**严重**：
- 某幕完全没有节点

**警告**：
- 某幕节点数不足
- 节点描述过短

**提示**：
- 建议细化某节点

---

## 🚦 就绪状态判定

### 评分等级

```
90-100分：优秀 ✨
  → 可以开始分集创作
  → 基础扎实，质量有保障

75-89分：良好 ✅
  → 建议优化部分内容后开始
  → 列出非阻断性问题清单

60-74分：及格 ⚠️
  → 需要完善关键问题
  → 列出必须解决的问题

<60分：不及格 ❌
  → 建议补充基础设定
  → 阻断进入分集阶段
```

## 🤖 AI深度诊断维度

### 快速诊断 vs AI诊断

| 维度 | 快速诊断 | AI深度诊断 |
|------|----------|-----------|
| 字段完整性 | ✅ 规则检查 | ✅ 智能评估 |
| 字数统计 | ✅ 精确计算 | ✅ 质量评估 |
| 逻辑自洽性 | ❌ | ✅ 深度分析 |
| 类型匹配度 | ✅ 关键词 | ✅ 语义理解 |
| 创意建议 | ❌ | ✅ 专业建议 |
| 市场预判 | ❌ | ✅ 趋势分析 |

### AI诊断额外价值

1. **世界观自洽性分析**
   - 时间线/空间设定是否矛盾
   - 世界观规则是否一致
   - 背景设定的独特性评估

2. **角色立体度评估**
   - 性格是否鲜明、有辨识度
   - 背景能否支撑行为动机
   - 主角成长空间预判

3. **关系张力分析**
   - 关系网络的冲突张力评分
   - 最有潜力的CP组合建议
   - 关系发展弧线预测

4. **大纲逻辑评估**
   - 三幕节奏是否符合短剧特点
   - 关键转折点设置合理性
   - 情感线和剧情线交织度

5. **商业价值预判**
   - 题材市场热度分析
   - 爆款要素覆盖度
   - 目标受众契合度
