## 🔑 关键变更点

### 技术栈确定
| 技术 | 原方案 | 确定方案 |
|------|--------|----------|
| 前端框架 | React / Vue 3 | **Vue 3** |
| UI组件 | Ant Design / Element Plus / shadcn/ui | **Element Plus** |
| 编辑器 | Quill / TipTap / Monaco Editor | **Monaco Editor** |
| 状态管理 | Zustand / Pinia | **Pinia** |
| 路由 | 需选择 | **Vue Router 4** (RealWeb已有) |
| HTTP | 需封装 | **request.js** (RealWeb已有) |

### 集成方式确定
- ✅ 作为RealWeb工具模块集成
- ✅ 复用用户系统和权限管理
- ✅ 使用 `shared/static-tools.json` 注册
- ✅ 通过后台"同步静态工具"功能发布

### 开发流程调整
- 新增"阶段0：集成准备"（1-2天）
- 其他阶段保持不变
