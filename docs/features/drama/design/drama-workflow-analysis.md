# 短剧剧本工作流程全面分析与优化建议

**分析时间**：2025-10-13  
**分析对象**：AI短剧脚本生成器完整工作流  
**目标**：识别可优化点和补充核心功能

---

## 📊 当前工作流程全景图

### 完整流程图
```
1. 项目列表页
   ↓ [创建项目]
2. 新建项目对话框
   ↓ [填写基本信息]
3. 工作台 - 世界观设定
   ↓ [保存世界观]
4. 工作台 - 角色管理
   ↓ [创建/编辑角色]
5. 工作台 - 剧情大纲
   ↓ [生成/编辑大纲]
6. 工作台 - 提示词模板
   ↓ [配置AI提示词]
7. 工作台 - 分集剧本
   ↓ [批量生成/逐集编辑]
8. 工作台 - 数据统计
   ↓ [查看进度和统计]
9. 工作台 - 版本历史
   ↓ [版本对比/恢复]
10. 导出剧本
    ↓ [TXT/Markdown/自定义]
```

## 🔍 核心模块深度分析

### 模块 1：项目列表页（index.vue）

#### 当前功能
✅ 项目展示（卡片/列表）  
✅ 统计信息（总数、完成、进行中、总集数）  
✅ 新建项目  
✅ 编辑项目  
✅ 删除项目  
✅ 导出项目  
✅ 刷新列表  

#### 🚨 发现的问题
1. ❌ **无项目筛选功能** - 项目多时难以查找
2. ❌ **无排序功能** - 不能按创建时间、修改时间、进度排序
3. ❌ **无项目搜索** - 无法快速定位项目
4. ❌ **无项目标签/分类** - 无法组织管理项目
5. ⚠️ **无项目模板** - 每次都要从头设置
6. ⚠️ **无快速预览** - 需要打开才能看内容
7. ⚠️ **无项目复制/克隆** - 无法基于现有项目快速创建

#### 💡 优化建议

##### 高优先级
1. **项目搜索功能** ⭐⭐⭐⭐⭐
   - 搜索项目名称、描述、类型
   - 实时搜索，即时过滤
   ```vue
   <el-input
     v-model="searchKeyword"
     placeholder="搜索项目..."
     :prefix-icon="Search"
     clearable
   />
   ```

2. **项目筛选和排序** ⭐⭐⭐⭐⭐
   - 按状态筛选（设定中、大纲中、剧本中、已完成）
   - 按类型筛选（霸道总裁、悬疑推理等）
   - 按时间排序（创建时间、修改时间）
   - 按进度排序
   ```vue
   <el-select v-model="filterStatus">
     <el-option label="全部" value="all" />
     <el-option label="设定中" value="设定中" />
     <el-option label="大纲中" value="大纲中" />
     <el-option label="剧本中" value="剧本中" />
     <el-option label="已完成" value="已完成" />
   </el-select>
   ```

3. **项目快速预览** ⭐⭐⭐⭐
   - 鼠标悬停显示详细信息
   - 显示角色数、分集数、进度等
   - 显示最后修改时间
   ```vue
   <el-tooltip placement="top">
     <template #content>
       <div>角色：5个</div>
       <div>分集：20/60</div>
       <div>最后修改：2小时前</div>
     </template>
     <ProjectCard :project="project" />
   </el-tooltip>
   ```

##### 中优先级
4. **项目模板功能** ⭐⭐⭐⭐
   - 预置常见类型模板（霸道总裁、悬疑推理等）
   - 包含预设世界观、角色框架
   - 快速启动项目
   ```javascript
   const templates = {
     霸道总裁: {
       worldview: { ... },
       characters: [
         { name: '男主', role: '总裁' },
         { name: '女主', role: '普通员工' }
       ]
     }
   };
   ```

5. **项目克隆功能** ⭐⭐⭐⭐
   - 基于现有项目创建新项目
   - 复制世界观、角色、大纲
   - 不复制具体剧本内容

6. **项目标签/分类** ⭐⭐⭐
   - 自定义标签（如"急稿"、"精品"等）
   - 按标签分组显示
   - 标签管理

### 模块 2：工作台总体（workbench.vue）

#### 当前功能
✅ 左侧导航菜单  
✅ 顶部面包屑和项目信息  
✅ 进度条显示  
✅ 快速导出  
✅ 项目设置  
✅ 7个核心模块切换  

#### 🚨 发现的问题
1. ❌ **无快捷键支持** - 切换模块需要点击
2. ❌ **无工作流引导** - 新手不知道从哪开始
3. ❌ **无任务清单** - 不清楚还有哪些待完成
4. ⚠️ **无自动保存** - 可能丢失未保存内容
5. ⚠️ **无协作功能** - 无法多人协作
6. ⚠️ **无评论/备注** - 无法添加创作想法

#### 💡 优化建议

##### 高优先级
1. **新手引导流程** ⭐⭐⭐⭐⭐
   - 首次打开显示引导提示
   - 逐步引导完成世界观→角色→大纲→剧本
   - 可跳过的引导步骤
   ```vue
   <el-tour v-model="showTour" :steps="tourSteps">
     <template #default="{ current }">
       {{ tourSteps[current].description }}
     </template>
   </el-tour>
   ```

2. **任务清单/进度检查** ⭐⭐⭐⭐⭐
   - 显示待完成任务（未设置世界观、未创建角色等）
   - 智能提示下一步操作
   - 进度百分比计算
   ```vue
   <el-progress :percentage="completionRate">
     <div class="task-list">
       ✅ 世界观已设置
       ❌ 角色未创建（建议至少2个）
       ⏳ 大纲进行中
     </div>
   </el-progress>
   ```

3. **自动保存功能** ⭐⭐⭐⭐⭐
   - 5分钟自动保存一次
   - 检测到内容变化才保存
   - 显示"已保存"/"保存中"状态
   ```javascript
   // 自动保存逻辑
   let autoSaveTimer = null;
   const startAutoSave = () => {
     autoSaveTimer = setInterval(() => {
       if (hasUnsavedChanges.value) {
         autoSave();
       }
     }, 5 * 60 * 1000); // 5分钟
   };
   ```

##### 中优先级
4. **快捷键支持** ⭐⭐⭐⭐
   - Ctrl+S 快速保存
   - Ctrl+1~7 切换模块
   - Ctrl+E 快速导出
   ```javascript
   onMounted(() => {
     document.addEventListener('keydown', handleKeyPress);
   });
   
   const handleKeyPress = (e) => {
     if (e.ctrlKey && e.key === 's') {
       e.preventDefault();
       saveCurrentModule();
     }
   };
   ```

5. **全局笔记/备注** ⭐⭐⭐
   - 每个模块可添加创作笔记
   - 支持富文本编辑
   - 笔记可搜索

6. **工作区布局自定义** ⭐⭐⭐
   - 侧边栏可折叠
   - 模块可拖拽排序
   - 记住用户偏好

   ```vue
   <el-button @click="generateWorldview">
   ```

2. **智能提示和示例** ⭐⭐⭐⭐⭐
   - 每个字段显示说明和示例

   ```vue
   <el-form-item label="故事背景">
     <el-input v-model="worldview.background" />
   ```

   - 检查每个字段是否填写
   - 检查字数是否合理
   - 给出完整度百分比和改进建议
   ```vue
   <el-alert type="warning">
     完整度：60%
     - ✅ 故事背景已填写（200字）
     - ⚠️ 核心主题过短（建议50字以上）
   ```

5. **自定义字段** ⭐⭐⭐
   - 允许添加额外字段
   - 如"魔法体系"、"科技水平"等
   - 字段可重命名

6. **世界观关系图** ⭐⭐⭐
   - 可视化展示设定之间的关系
   - 冲突与角色关系图
   - 帮助理清思路

### 模块 4：角色管理（CharacterManager.vue）

#### 当前功能
✅ 创建/编辑/删除角色  
✅ 角色卡片展示  
✅ 角色详情对话框  
✅ 角色字段（姓名、定位、描述等）  

#### 🚨 发现的问题
1. ❌ **无角色关系图** - 无法可视化角色关系
2. ❌ **无AI生成角色** - 需要手动创建所有角色
3. ❌ **无角色模板** - 每次从头创建
4. ⚠️ **角色间关系不明确** - 只有文字描述
5. ⚠️ **无角色成长弧线** - 无法规划角色发展
6. ⚠️ **无角色冲突矩阵** - 不清楚角色间的冲突点

#### 💡 优化建议

##### 高优先级
1. **AI智能生成角色** ⭐⭐⭐⭐⭐
   - 根据世界观和剧本类型生成主要角色
   - 自动生成角色关系
   - 性格、背景、动机自动匹配
   ```javascript
   const generateCharacters = async (worldview, type) => {
     // 调用AI生成主角、配角、反派
     const prompt = `根据${type}类型和世界观：${worldview}，生成3-5个主要角色`;
     return await callAI(prompt);
   };
   ```

2. **角色关系图谱** ⭐⭐⭐⭐⭐
   - 可视化角色关系网络
   - 显示亲密度、冲突度
   - 可拖拽调整位置
   ```vue
   <div class="character-graph">
     <CharacterNode
       v-for="character in characters"
       :character="character"
       :relationships="getRelationships(character)"
     />
   </div>
   ```

3. **角色关系编辑器** ⭐⭐⭐⭐⭐
   - 快速建立角色间关系
   - 定义关系类型（朋友、敌人、爱人等）
   - 关系强度评分（1-10）
   ```vue
   <el-form-item label="与其他角色的关系">
     <div v-for="other in otherCharacters" class="relationship-item">
       <span>{{ other.name }}</span>
       <el-select v-model="relationship.type">
         <el-option label="朋友" value="friend" />
         <el-option label="敌人" value="enemy" />
         <el-option label="爱人" value="lover" />
       </el-select>
       <el-slider v-model="relationship.strength" :min="1" :max="10" />
     </div>
   </el-form-item>
   ```

##### 中优先级
4. **角色成长弧线** ⭐⭐⭐⭐
   - 规划角色在不同集数的状态变化
   - 性格、目标、状态的演变
   - 可视化展示
   ```vue
   <CharacterArc :character="character" :episodes="episodes">
     - 第1集：冷漠自闭
     - 第30集：开始改变
     - 第60集：温暖开朗

   ```

5. **角色冲突矩阵** ⭐⭐⭐⭐
   - 分析每对角色的冲突点
   - 冲突强度评分
   - 冲突来源（利益、价值观、误会等）

   ```
   角色冲突矩阵:
   ```

   - 快速应用模板
   - 自动填充基础信息

### 模块 5：剧情大纲（OutlineEditor.vue）

#### 当前功能
✅ 三幕结构  
✅ 幕次编辑  
✅ 关键节点  
✅ 生成提示词  

#### 🚨 发现的问题
1. ❌ **无AI智能生成大纲** - 需要手动填写
2. ❌ **结构固定** - 只支持三幕，无法自定义
3. ❌ **无节奏建议** - 不知道哪里该高潮哪里该缓
4. ⚠️ **节点与分集对应不清** - 难以规划分集分布
5. ⚠️ **无大纲模板** - 每次从头写
6. ⚠️ **无冲突升级图** - 看不出冲突走向

#### 💡 优化建议

##### 高优先级
1. **AI智能生成大纲** ⭐⭐⭐⭐⭐
   - 根据世界观、角色、集数自动生成
   - 生成三幕结构和关键节点
   - 自动分配节点到集数
   ```javascript
   const generateOutline = async (worldview, characters, episodeCount) => {
     const prompt = `
       世界观：${worldview}
       主要角色：${characters}
       总集数：${episodeCount}
       
       请生成完整的三幕剧情大纲，包括每一幕的关键节点和对应集数范围。
     `;
     return await callAI(prompt);
   };
   ```

2. **灵活的大纲结构** ⭐⭐⭐⭐⭐
   - 支持三幕、五幕、自定义幕数
   - 可添加/删除幕次
   - 幕次可重命名
   ```vue
   <el-select v-model="outline.structure">
     <el-option label="三幕结构" value="three-act" />
     <el-option label="五幕结构" value="five-act" />
     <el-option label="自定义" value="custom" />
   </el-select>
   ```

3. **节点与分集映射** ⭐⭐⭐⭐⭐
   - 每个节点标注对应的集数范围
   - 可视化展示节点分布
   - 自动检查覆盖完整性
   ```vue
   <div class="node-timeline">
     <div v-for="node in plotPoints" class="node-item">
       <span>{{ node.name }}</span>
       <el-input-number v-model="node.startEpisode" />
       -
       <el-input-number v-model="node.endEpisode" />
     </div>
   </div>
   ```

##### 中优先级
4. **节奏建议和分析** ⭐⭐⭐⭐
   - AI分析大纲节奏
   - 标注高潮、低潮、转折
   - 建议调整
   ```vue
   <el-alert type="info">
     📊 节奏分析：
     - 第1-10集：节奏平缓（✅ 合理）
     - 第11-20集：缺少高潮点（⚠️ 建议在第15集添加冲突）
     - 第21-30集：转折密集（⚠️ 建议分散）
   </el-alert>
   ```

5. **冲突升级曲线** ⭐⭐⭐⭐
   - 可视化展示冲突强度走向
   - 自动检测是否符合剧情曲线
   - 拖拽调整曲线
   ```vue
   <ConflictCurve :plotPoints="plotPoints">
     <svg>
       <path d="..." /> <!-- 冲突强度曲线 -->
     </svg>
   </ConflictCurve>
   ```

6. **大纲模板库** ⭐⭐⭐
   - 不同类型的经典大纲模板
   - 导入模板快速开始
   - 社区优秀大纲分享

#### 当前功能
✅ 分集列表展示  
✅ 创建/编辑分集  
✅ AI生成剧本  
✅ 状态管理（草稿、完成、审核）  
✅ 批量生成  

#### 🚨 发现的问题

6. ⚠️ **无批量编辑** - 修改相同内容很麻烦

   ```vue
   <div class="episode-editor">
   ```

   - 自动识别对白、旁白、场景
   - 统一格式（角色名、对白格式）
   - 一键格式化
   ```javascript
   const formatScript = (content) => {
     // 识别并格式化
     // [场景] 背景描述
     // 角色名：对白
     // （旁白）
     return formatted;
   };
   ```

3. **分集连贯性检查** ⭐⭐⭐⭐⭐

   ```vue
     🔍 连贯性检查：
   ```

##### 中优先级

   - 从对白、节奏、冲突等维度打分
   - 给出改进建议
