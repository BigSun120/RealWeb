## ⚙️ **第五阶段：服务配置**

### **5.1 配置Nginx**
```bash
# 在新服务器执行
cp /root/backup_$(date +%F)/nginx.conf /etc/nginx/nginx.conf
nginx -t
systemctl reload nginx
echo "✅ Nginx配置完成"
```

### **5.2 启动Inbucket邮件服务**
```bash
# 在新服务器执行
docker run -d --name inbucket-temp --restart unless-stopped \
  -p 9000:9000 -p 2500:2500 -p 1100:1100 \
  -e INBUCKET_SMTP_DOMAIN=godaug.fun,localhost,test.local \
  -e INBUCKET_SMTP_ADDR=0.0.0.0:2500 \
  -e INBUCKET_WEB_ADDR=0.0.0.0:9000 \
  -e INBUCKET_STORAGE_TYPE=file \
  -e INBUCKET_STORAGE_PARAMS=/data \
  -v /var/lib/inbucket:/data \
  inbucket/inbucket:latest
echo "✅ Inbucket邮件服务启动完成"
```

### **5.3 配置PM2并启动后端**
```bash
# 在新服务器执行
cd /root/RealWeb
cp /root/backup_$(date +%F)/ecosystem.config.js ./ 2>/dev/null || echo "使用默认PM2配置"
pm2 start backend/app.js --name website-backend
pm2 save
pm2 startup
echo "✅ 后端服务启动完成"
```

### **5.4 构建前端**
```bash
# 在新服务器执行

npm run build
cp -r dist/* /var/www/html/
echo "✅ 前端构建部署完成"
```

## 💡 **重要提示**

1. **迁移时机**: 建议在用户访问量较低的时段进行（如凌晨2-4点）
2. **备份验证**: 每个备份步骤完成后都要验证文件完整性
3. **分步执行**: 不要急于一次性完成，每个阶段都要确认无误
4. **保留旧服务器**: 迁移后至少保留旧服务器7天，确认新服务器稳定
5. **监控告警**: 迁移后密切监控新服务器状态24-48小时

## 📞 **常见问题解决**

### **MongoDB连接失败**
```bash
# 检查MongoDB状态
systemctl status mongod
# 重启MongoDB
systemctl restart mongod
```

### **PM2进程异常**
```bash
# 重启PM2进程
pm2 restart all
# 查看错误日志
pm2 logs --err
```

### **Nginx配置错误**
```bash
# 测试配置文件
nginx -t
# 重新加载配置
systemctl reload nginx
```

### **Docker容器异常**
```bash
# 查看容器状态
docker ps -a
# 重启容器
docker restart inbucket-temp
```
