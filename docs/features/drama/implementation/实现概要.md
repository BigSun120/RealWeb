# AI短剧剧本生成工具 - 实现概要

> 最后更新：2025-10-13

---

## 📋 项目概述

AI短剧剧本生成工具是 RealWeb 平台的核心生产力工具，帮助用户通过 AI 辅助快速创作短剧剧本。

### 核心价值
- ✅ 提供结构化的剧本创作流程
- ✅ 集成 AI 提示词生成和回答解析
- ✅ 支持完整的项目管理和版本控制
- ✅ 提供多格式导出功能

---

## 🏗️ 技术架构

### 前端技术栈
- **框架**: Vue 3 + Composition API
- **UI库**: Element Plus
- **状态管理**: Pinia
- **路由**: Vue Router 4
- **HTTP**: Axios (封装的 request.js)

### 后端技术栈
- **框架**: Node.js + Express
- **数据库**: MongoDB + Mongoose
- **验证**: Express-validator
- **认证**: JWT (RealWeb 用户系统)

### 数据模型
**核心模型**: `DramaProject`

主要字段：
- 项目基础信息（名称、类型、状态、进度等）
- 世界观设定（背景、主题、冲突、基调等）
- 角色列表（姓名、性格、背景、关系等）
- 剧情大纲（三幕结构、关键节点）
- 分集管理（标题、内容、状态、字数等）
- 版本历史（自动记录）

## ✨ 已实现功能

### 阶段 0：集成准备 ✅

- ✅ 路由配置和权限设置
- ✅ 目录结构和组件框架

### 阶段 1：项目管理 MVP ✅

#### 后端 API
- `GET /api/tools/drama/projects` - 获取项目列表（分页、搜索、筛选）
- `GET /api/tools/drama/projects/:id` - 获取项目详情
- `POST /api/tools/drama/projects` - 创建项目
- `PUT /api/tools/drama/projects/:id` - 更新项目
- `DELETE /api/tools/drama/projects/:id` - 删除项目
- `GET /api/tools/drama/statistics` - 获取统计信息

#### 前端功能
- 项目列表页面（网格/列表双视图）
- 项目创建/编辑/删除
- 搜索和筛选
- 统计卡片展示
- 工作台主界面

### 阶段 2：世界观与角色 ✅

#### WorldviewEditor（世界观编辑器）
- 故事背景、世界设定、核心主题
- 主要冲突、情感基调
- 生成世界观提示词
- 粘贴 AI 回答并自动解析
- 保存功能

#### CharacterManager（角色管理器）
- 角色列表展示（卡片视图）
- 添加/编辑/删除角色
- 角色详细信息（8+字段）
- 生成角色提示词
- 批量角色 AI 生成
- AI 回答智能解析

### 阶段 3：大纲与分集 ✅

#### OutlineEditor（大纲编辑器）
- 三幕结构编辑
- 关键节点管理
- 节点详细信息（事件、角色、情感、集数）
- 统计信息（节点数、角色数、预估集数）
- 生成大纲提示词
- AI 智能生成大纲

#### EpisodeManager（分集管理器）
- 双视图模式（卡片/列表）
- 添加/编辑/删除分集
- 分集状态管理（草稿/进行中/已完成/已审核）
- 生成分集提示词
- 批量创建分集
- 字数统计和排序

### 阶段 4：AI 集成系统 ✅

#### AI 回答解析器（AIResponseParser）
- 智能解析 AI 回答内容
- 支持世界观和角色解析
- 置信度评估（高/中/低/未识别）
- 字段级手动编辑
- 成功率统计
- 一键填充到表单

#### 解析策略
- 标记化内容识别（【】、**、##、：）
- 段落级关键词匹配
- 正则表达式提取
- 智能字段长度控制

### 阶段 5：提示词系统 ✅

#### PromptDialog（提示词对话框）
- 显示生成的提示词
- 提示词编辑功能
- 一键复制到剪贴板
- 字符统计
- 使用指引

#### 提示词模板引擎（promptTemplates.js）
- `generateWorldviewPrompt()` - 世界观提示词
- `generateCharacterPrompt()` - 角色提示词
- `generateBatchCharactersPrompt()` - 批量角色
- `generateOutlinePrompt()` - 大纲提示词
- `generateEpisodePrompt()` - 分集提示词
- `generateBatchEpisodesPrompt()` - 批量分集

### 阶段 6：导出功能 ✅

#### 导出格式
- TXT 纯文本格式
- Markdown 富文本格式

#### 导出选项
- 包含/排除未完成剧集
- 指定导出范围（前N集）

#### 导出内容
- 项目基本信息
- 世界观设定
- 主要角色列表
- 分集剧本详细内容

#### 后端实现
- `dramaExporter.js` - 导出核心模块
- `GET /api/tools/drama/projects/:id/export` - 导出 API

### 阶段 7：版本历史 ✅

#### 版本管理功能
- 自动记录关键修改
- 版本对比（世界观、角色、大纲）
- 版本回滚
- 变更详情展示

## 🔄 工作流程

### 标准创作流程

```
1. 创建项目
   ↓
2. 设定世界观 → 生成提示词 → AI回答 → 解析填充
   ↓
3. 创建角色 → 批量生成 → AI回答 → 批量导入
   ↓
4. 编辑大纲 → 添加节点 → 生成提示词 → AI生成
   ↓
5. 创建分集 → 批量创建 → 生成提示词 → 逐集完善
   ↓
6. 导出剧本 → 选择格式 → 下载文件
```

### AI 辅助工作流

```
用户填写基础信息
   ↓
系统生成提示词
   ↓
用户复制到 ChatGPT/Claude
   ↓
AI 生成内容
   ↓
用户粘贴回工具
   ↓
系统智能解析
   ↓
自动填充表单
   ↓
用户审核调整
   ↓
保存到数据库
```

## 📝 已知限制

1. **AI 依赖**：需要用户手动复制粘贴，未实现 API 直连
2. **导出格式**：仅支持 TXT 和 Markdown，不支持 PDF/DOCX
3. **协作功能**：暂不支持多人协作编辑
4. **版本控制**：版本历史仅记录关键节点，不是完整的版本管理系统
5. **离线功能**：需要网络连接，不支持离线编辑

### 常见问题

**Q: 如何添加新的提示词模板？**  
A: 在 `utils/promptTemplates.js` 中添加新的生成函数。

**Q: 如何添加新的导出格式？**  
A: 在 `backend/src/utils/dramaExporter.js` 中添加新的格式化函数。

**Q: 如何扩展角色字段？**  
A: 修改 `DramaProject` 模型和 `CharacterDialog` 组件。

**Q: 如何优化大项目性能？**  
A: 实现分页加载、虚拟滚动、懒加载图片等技术。
