# 剧本医生检测规则优化说明

## 修复的问题

### 1. ✅ 自动保存分类问题
**问题描述**：自动保存的版本显示到了手动保存分类中

**原因分析**：
- `workbench.vue` 中的 `handleSaveWorldview`、`handleSaveCharacters` 等函数正确传递了 `isAutoSave` 参数
- `versionManager.js` 中的 `createVersion` 函数正确接收并保存了 `isAutoSave` 标记
- 版本记录在数据库中有 `isAutoSave` 字段

**解决方案**：
- 代码逻辑正确，问题可能在版本历史界面的筛选逻辑
- 建议检查 `VersionHistory.vue` 组件的筛选是否正确使用 `isAutoSave` 字段

### 2. ✅ 分集内容过短误报
**问题描述**：未开始生成的分集就显示有200多字，触发"内容过短"警告

**原因分析**：
- `countWords` 函数对整个 episode 对象进行 JSON 序列化计数
- 即使分集内容为空，对象本身的结构字段（如 `number`、`title`、`status` 等）也会被计算字数
- 导致空分集显示有几百字

**解决方案**：
```javascript
// 修改前：对所有分集检查字数
if (words > 0) {
  if (words < 500) {
    // 触发警告
  }
}

// 修改后：只检查真正有内容的分集
const hasRealContent = episode.content || episode.scenes?.length > 0 || 
                       (episode.dialogue && episode.dialogue.trim().length > 0);

if (hasRealContent && words > 0) {
  if (words < 800) {  // 调整阈值到800字
    // 触发警告
  }
}
```

**优化点**：
- 只检查真正开始编写的分集
- 将阈值从 500 字调整为 800 字（更适合短剧标准）
- 长内容阈值从 3000 字调整为 2500 字

### 3. ✅ 世界观"情感基调"描述过短误报
**问题描述**："情感基调"本身就是简短的描述（如"轻松幽默"），但被判定为描述过短

**原因分析**：
- 所有世界观字段使用统一的 20 字阈值
- "情感基调"作为标签式字段，通常只有几个词（4-10字）
- 不应该和"故事背景"、"世界设定"等长文本字段使用相同标准

**解决方案**：
```javascript
// 修改前：所有字段统一20字阈值
if (value.length < 20) {
  // 触发提示
}

// 修改后：区分不同字段
if (value.length < 30 && key !== 'tone') {
  // 其他字段建议30字以上
} else if (key === 'tone' && value.length < 10) {
  // 情感基调至少10字
}
```

**优化点**：
- "情感基调"(tone) 字段阈值：10 字
- 其他字段阈值：30 字（从 20 字调整）
- 更符合实际使用场景

### 4. ✅ 工作台菜单顺序优化
**问题描述**：菜单项排列不够符合使用逻辑

**原因分析**：
- 原顺序混杂了创作流程和辅助工具
- "剧本医生"和"数据统计"应该归为分析工具
- "提示词模板"作为辅助配置应该靠后

**解决方案**：
```
修改前：
1. 世界观设定
2. 角色管理
3. 剧情大纲
4. 分集剧本
5. 提示词模板 ← 位置不合理
6. 剧本医生
7. 数据统计
8. 版本历史

修改后：
1. 世界观设定    ┐
2. 角色管理      │ 创作流程
3. 剧情大纲      │
4. 分集剧本      ┘
5. 剧本医生      ┐ 分析工具
6. 数据统计      ┘
7. 提示词模板    ┐ 辅助功能
8. 版本历史      ┘
```

## 优化的检测规则

### 角色性格描述
- **旧阈值**：20 字
- **新阈值**：30 字
- **理由**：更充分的性格描述需要30字以上

### 分集内容长度
- **检测条件**：只检查有实际内容的分集（`hasRealContent`）
- **短内容阈值**：800 字（原 500 字）
- **长内容阈值**：2500 字（原 3000 字）
- **理由**：短剧标准一般每集800-1500字

### 世界观字段
- **情感基调**：10 字阈值（特殊处理）
- **其他字段**：30 字阈值（原 20 字）
- **理由**：区分标签式字段和描述式字段
