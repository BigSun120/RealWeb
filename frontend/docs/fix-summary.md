### ✅ 1. 自动保存分类问题
**问题描述**：自动保存的版本显示到了手动保存分类中

**根本原因**：
- `VersionHistory.vue` 的筛选逻辑使用 `!v.isAutoSave` 判断手动保存
- 但旧版本可能没有 `isAutoSave` 字段（undefined），导致被判定为手动保存
- 新的自动保存版本 `isAutoSave = true` 被正确筛选出来，但可能在UI上显示混乱

**修复方案**：
```javascript
// 修改前
result = result.filter(v => !v.isAutoSave);

// 修改后  
result = result.filter(v => v.isAutoSave !== true);
```

**修复位置**：
- `VersionHistory.vue` 第 417 行

**测试方法**：
1. 执行一次自动保存（等待1小时或手动触发）
2. 打开版本历史
3. 点击"自动保存"标签，应该只显示自动保存的版本
4. 点击"手动保存"标签，应该不包含自动保存的版本

### ✅ 2. 分集内容过短误报
**问题描述**：未开始生成的空分集显示有200多字，触发"内容过短"警告

**根本原因**：
- `countWords` 函数对整个 episode 对象进行 JSON 序列化
- 空分集也有 `number`、`title`、`status` 等结构字段
- 这些字段被计算到字数中，导致空分集显示几百字

**修复方案**：
```javascript
// 增加内容检测
const hasRealContent = episode.content || 
                       episode.scenes?.length > 0 || 
                       (episode.dialogue && episode.dialogue.trim().length > 0);

// 只检查有实际内容的分集
if (hasRealContent && words > 0) {
  if (words < 800) {
    // 触发警告
  }
}
```

**修复位置**：
- `analysisEngine.js` 第 294-318 行

**阈值调整**：
- 短内容：500字 → 800字（短剧标准）
- 长内容：3000字 → 2500字

**测试方法**：
1. 创建新项目，不添加任何分集内容
2. 打开剧本医生
3. 应该不会显示"分集内容过短"警告

### ✅ 3. 世界观"情感基调"描述过短误报
**问题描述**："情感基调"字段输入"轻松幽默"（4字）被判定为描述过短

**根本原因**：
- 所有世界观字段统一使用 20 字阈值
- "情感基调"是标签式字段，通常只有几个词
- 不应该和"故事背景"、"世界设定"等长文本字段使用相同标准

**修复方案**：
```javascript
// 区分字段类型
if (value.length < 30 && key !== 'tone') {
  // 其他字段：至少30字
} else if (key === 'tone' && value.length < 10) {
  // 情感基调：至少10字
}
```

**修复位置**：
- `analysisEngine.js` 第 363-377 行

**阈值调整**：
| 字段 | 旧阈值 | 新阈值 | 说明 |
|------|--------|--------|------|
| 情感基调(tone) | 20字 | 10字 | 标签式字段 |
| 其他字段 | 20字 | 30字 | 描述式字段 |

**测试方法**：
1. 世界观-情感基调输入"轻松"（2字）→ 应该提示过短
2. 输入"轻松幽默"（4字）→ 应该提示过短
3. 输入"轻松幽默、甜蜜温馨"（10字）→ 不应该提示
4. 故事背景输入20字内容 → 应该提示过短
5. 故事背景输入30字以上 → 不应该提示
