## 2. 灵感库

### 2.1 灵感记录 【P1】

#### 2.1.1 快速记录
**功能**:
- 浮动按钮（随时记录）
- 快捷键（Ctrl+I）
- 自动保存时间戳

**记录内容**:
```
┌────────────────────────────┐
│  💡 新灵感                 │
│  ────────────────────────  │
│  标题: [可选]              │
│  内容:                     │
│  [文本输入框]              │
│                            │
│  标签: #对白 #场景         │
│  关联: 第15集              │
│                            │
│  [保存]  [取消]            │
└────────────────────────────┘
```

#### 2.1.2 灵感类型
- **对白灵感**: 精彩的对话片段
- **场景灵感**: 有趣的场景设定
- **情节灵感**: 转折点、冲突设计
- **人物灵感**: 角色行为、性格表现
- **其他**: 自由记录

### 2.2 灵感管理 【P1】

#### 2.2.1 灵感列表
**显示方式**:
- 卡片视图（默认）
- 列表视图（紧凑）
- 时间线视图（按时间排序）

**卡片内容**:
```
┌─────────────────────┐
│  💬 对白灵感        │
│  2025-10-12 14:30   │
│  ─────────────────  │
│  "有些事，不是你    │
│   想忘就能忘的"     │
│                     │
│  #对白 #第10集      │
│  [编辑] [应用]      │
└─────────────────────┘
```

#### 2.2.2 灵感筛选
- 按类型筛选
- 按标签筛选
- 按关联集数筛选
- 按时间范围筛选
- 搜索关键词

#### 2.2.3 灵感应用
- **拖拽应用**: 拖到剧本编辑器中
- **一键插入**: 点击"应用"自动插入
- **标记已用**: 应用后自动标记

### 2.3 灵感同步与备份 【P2】
- 导出灵感库（JSON/TXT）
- 导入灵感库
- 云端同步（可选）

## 3. 系统设置与配置

### 3.1 通用设置 【P0】

#### 3.1.1 界面设置
- **主题**: 
  - 亮色主题
  - 暗色主题
  - 自动切换（跟随系统）
- **语言**: 简体中文/繁体中文/English（后期）
- **字体大小**: 小/中/大
- **界面缩放**: 90% / 100% / 110% / 120%

#### 3.1.2 编辑器设置
- **字体**: 宋体/黑体/微软雅黑/自定义
- **行高**: 1.0 / 1.5 / 2.0
- **自动保存**: 开启/关闭，间隔（1/3/5/10分钟）
- **拼写检查**: 开启/关闭
- **自动补全**: 开启/关闭（角色名、地点名）

### 3.2 AI平台配置 【P0】

**默认平台设置**:
- **首选平台**: ChatGPT / Claude / 文心一言 / 自定义
- **字数限制**: 自动设置或手动输入
- **Token限制**: 自动计算或手动输入

**平台特性配置**:
```
ChatGPT 4.0:
- 字数限制: 8000字
- Token限制: 约10000
- 适用场景: 高质量创作

Claude:
- 字数限制: 20000字
- Token限制: 约30000
- 适用场景: 长文本处理
```

### 3.3 导出默认设置 【P1】

**Markdown导出**:
- 默认包含: 项目信息/角色表/大纲/剧本
- 文件命名: 《项目名》_剧本_日期.md

**Word导出**:
- 默认字体: 宋体
- 默认字号: 12pt
- 默认行距: 1.5倍
- 页边距: 普通

**PDF导出**:
- 纸张大小: A4
- 添加书签: 是
- 添加水印: 否

### 3.4 数据管理 【P1】

#### 3.4.1 存储管理
- **查看存储**: 已用空间/可用空间
- **缓存清理**: 清除临时文件
- **数据导出**: 完整数据备份
- **数据恢复**: 从备份恢复

#### 3.4.2 自动备份
- **启用自动备份**: 是/否
- **备份频率**: 每天/每周/每月
- **备份位置**: 本地文件夹/云端
- **保留份数**: 最近5/10/20份
