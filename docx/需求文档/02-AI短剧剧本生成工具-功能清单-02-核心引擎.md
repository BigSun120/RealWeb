# 功能清单-02-核心引擎

> **模块说明**: 本模块是整个工具的核心，包括提示词生成器、上下文管理器和模板库系统

---

## 1. 智能提示词生成器

### 1.1 核心生成逻辑

#### 1.1.1 模板加载与变量替换 【P0】
**功能描述**: 从模板库加载模板并替换变量

**输入**:
- 任务类型（角色设计/大纲/剧本等）
- 项目数据（名称、类型、集数等）
- 用户自定义参数

**处理流程**:
```
1. 根据任务类型选择对应模板
2. 提取项目数据中的变量值
3. 使用正则替换模板中的{{变量}}
4. 返回替换后的文本
```

**技术要点**:
```javascript
// 变量替换引擎示例
function replaceVariables(template, data) {
  return template.replace(/\{\{(\w+)\}\}/g, (match, key) => {
    return data[key] || match;
  });
}
```

**验收标准**:
- [ ] 所有变量正确替换
- [ ] 未定义变量保持原样或显示占位符
- [ ] 支持嵌套数据访问（如{{project.name}}）

---

#### 1.1.2 上下文自动注入 【P0】
**功能描述**: 根据任务类型自动加载必要的上下文

**注入规则**:
```
角色设计 → 项目设定
大纲生成 → 项目设定 + 角色信息
分集梗概 → 项目设定 + 角色 + 大纲
详细剧本 → 项目设定 + 角色 + 大纲 + 梗概 + 前情提要
优化润色 → 原始剧本 + 优化要求
```

**技术要点**:
- 使用依赖图管理模块依赖关系
- 懒加载：只在需要时加载数据
- 缓存：避免重复读取相同数据

**验收标准**:
- [ ] 每种任务类型注入正确的上下文
- [ ] 上下文顺序合理
- [ ] 不注入无关信息

---

**验收标准**:

### 1.2 提示词优化

#### 1.2.1 字数/Token估算 【P0】
**功能描述**: 实时估算提示词的字数和Token数

**计算方法**:
- 中文字数：直接统计字符（排除空格和标点）
- 英文单词数：按空格分割
- Token估算（OpenAI）：字数 × 1.3（中文）/ 0.75（英文）
- Token估算（Claude）：字数 × 1.5

**显示**:
```
提示词统计：
- 总字符数：2,340
- 中文字数：2,100
- 预估Token（GPT）：2,730
- 预估Token（Claude）：3,150
```

**验收标准**:
- [ ] 实时计算，输入即更新
- [ ] 估算误差<15%
- [ ] 超过平台限制时提示警告

**测试用例**:
```
TC-1.2.1-01: 纯中文
- 输入: "这是一个测试"（6字）
- 预期: 字数=6, Token≈8

TC-1.2.1-02: 中英混合
- 输入: "Hello世界"
- 预期: 正确识别中英文并分别计算
```

#### 1.2.3 提示词压缩 【P1】
**功能描述**: 在不影响质量的前提下压缩提示词长度

**压缩策略**:
1. **删除冗余修饰词**：
   - "非常"、"特别"、"十分" → 删除
   
2. **合并相似描述**：
   - "性格善良、心地善良" → "性格善良"
   
3. **简化示例**：
   - 多个示例 → 保留1-2个典型示例
   
4. **结构化表达**：
   - 段落文字 → 列表/表格

**压缩等级**:
- 不压缩（100%）
- 轻度压缩（85-95%）
- 标准压缩（70-85%）
- 深度压缩（50-70%）

**验收标准**:
- [ ] 压缩后语义不变
- [ ] 可选择压缩等级
- [ ] 显示压缩比例

## 2. 上下文管理器

### 2.1 上下文压缩

#### 2.1.1 智能摘要生成 【P1】
**功能描述**: 将长文本自动压缩为摘要

**压缩方法**:

**A. 角色信息压缩**:
```
原文（150字）:
李雨晴，25岁，独立设计师。出身于富裕家族，从小接受良好教育，性格独立、善良但略显倔强。因不满家族安排的婚约，决定隐瞒身份进入陈墨的公司证明自己...

压缩后（50字）:
李雨晴（女主）：25岁设计师，富家女隐瞒身份进入男主公司，独立善良，核心目标是证明自己能力。
```

**B. 大纲压缩**:
```
原文（500字，3段详细描述）
压缩后（100字）:
第一幕（1-10集）：女主隐瞒身份进入公司，与男主相识产生误会，感情在工作中逐渐升温。
```

**技术要点**:
- 提取关键信息（姓名、年龄、身份、目标）
- 删除细节描写和修饰语
- 保留核心冲突和关系
- 使用"摘要模板"确保格式统一

**验收标准**:
- [ ] 压缩率30-50%
- [ ] 核心信息完整
- [ ] 可读性良好

### 2.3 分包策略

#### 2.3.1 智能分包算法 【P0】
**功能描述**: 当提示词过长时自动拆分为多个子任务

**拆分规则**:
```
1. 按平台限制确定每包最大字数
2. 优先按自然边界拆分（集数、场景）
3. 每包保留必要的公共上下文
4. 包之间添加衔接说明
```

**示例**:
```
任务：生成第1-15集剧本
平台限制：8000字/包
拆分方案：
  包1: 第1-5集 (7800字) + 公共上下文(1200字)
  包2: 第6-10集 (7600字) + 公共上下文(1200字)
  包3: 第11-15集 (7900字) + 公共上下文(1200字)
```

**公共上下文**:
- 项目基础信息（精简版）
- 主要角色摘要
- 大纲相关部分

**验收标准**:
- [ ] 每包不超过限制
- [ ] 拆分边界合理
- [ ] 上下文完整
