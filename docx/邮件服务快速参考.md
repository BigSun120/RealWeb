# 📧 邮件服务快速参考

## 🎯 当前状态

✅ **邮件服务已完全配置并正常工作**

### 功能概览
- **注册验证邮件**：发送到用户真实邮箱（Gmail、QQ邮箱等）
- **临时邮箱服务**：接收发送到 `@godaug.fun` 的邮件

## 🔧 服务架构

```
注册邮件流程：
用户注册 → 后端EmailService → Postfix(25) → 用户真实邮箱

临时邮箱流程：
外部邮件 → Postfix(25) → 虚拟域名转发 → Inbucket(2500)
```

## 🚨 常见问题解决

### 问题1：注册邮件发送失败
```bash
# 检查后端日志
pm2 logs website-backend

# 检查Postfix状态
systemctl status postfix
tail -f /var/log/mail.log
```

### 问题2：临时邮箱无法接收
```bash
# 检查Inbucket容器
docker ps | grep inbucket
docker logs inbucket-temp

# 检查Postfix虚拟域名配置
postconf virtual_mailbox_domains virtual_transport
```

### 问题3：服务重启后邮件服务异常
```bash
# 重启所有邮件服务
systemctl restart postfix
docker restart inbucket-temp

# 验证配置
postfix check
```

## 🔄 服务重启流程

### 完整重启
```bash
# 1. 停止服务
systemctl stop postfix
docker stop inbucket-temp

# 2. 启动服务
systemctl start postfix
docker start inbucket-temp

# 3. 验证状态
systemctl status postfix
docker ps | grep inbucket
```

### 仅重启Inbucket
```bash
docker restart inbucket-temp
```

## 📞 紧急处理

如果邮件服务完全失效：

1. **检查服务状态**：
   ```bash
   systemctl status postfix
   docker ps | grep inbucket
   ```

2. **查看错误日志**：
   ```bash
   tail -20 /var/log/mail.log
   pm2 logs website-backend --err
   ```

3. **重启服务**：
   ```bash
   systemctl restart postfix
   docker restart inbucket-temp
   pm2 restart website-backend
   ```

4. **验证功能**：
   - 测试注册新用户
   - 测试临时邮箱生成和接收
