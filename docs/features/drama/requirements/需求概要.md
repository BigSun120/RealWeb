# AI短剧剧本生成工具 - 需求概要

> 最后更新：2025-10-13  
> 版本：v1.0

---

## 📋 项目定位

**核心理念**：通过智能提示词管理，让用户在任何 AI 平台高效创作短剧剧本。

### 核心价值
- ✅ 无需 API 对接，手动复制提示词到任意 AI 平台
- ✅ 上下文自包含，每个提示词包含完整背景
- ✅ 推荐路径 + 自由模式，向导流程 + 自由跳转
- ✅ 专业化管理，版本控制、一致性检查、多格式导出

### 目标用户
- 短剧编剧（新手/专业）
- 内容创作者
- 自媒体从业者

---

## 🎯 核心功能模块

### 1. 项目管理
**功能**：
- 创建/编辑/删除项目
- 项目信息：名称、类型、集数、时长、状态
- 多项目管理、搜索筛选

### 2. 标准工作流（向导模式）
**7步创作流程**：
```
基础设定 → 角色设计 → 剧情大纲 → 分集梗概 
→ 详细剧本 → 优化润色 → 导出成品
```

**特性**：
- 进度可视化
- 每步可重复执行
- 支持跳转和返回

### 3. 自由创作模式
**功能**：
- 不受向导限制
- 卡片式独立管理
- 自由关联上下文
- 自定义提示词

### 4. 智能提示词生成（核心引擎）
**功能**：
- 自动组装上下文
- 上下文压缩优化
- 多平台适配（ChatGPT/Claude/文心一言等）
- 格式化输出约束

**上下文压缩策略**：
- 角色信息：保留核心性格和关系
- 大纲信息：结构化描述
- 前情提要：最近3集核心事件

### 5. 模板库系统
**预设模板类型**：
- 霸道总裁、悬疑推理、甜宠日常
- 复仇爽剧、古装穿越、职场励志

**任务模板**：
- 角色设计、大纲生成、对白打磨
- 场景描写、情感深化

### 6. 内容管理
**角色管理**：
- 角色卡片（姓名、性格、背景、关系）
- 富文本编辑
- 关系图谱（可选）

**大纲管理**：
- 三幕结构编辑
- 层级组织（幕/章/节）
- 拖拽调整顺序

**剧本管理**：
- 按集数/场次组织
- 场景标签（日/夜、内/外）
- 状态管理

### 7. 版本控制
**功能**：
- 自动记录关键修改
- 版本对比
- 版本回滚
- 变更日志

### 8. 质量检查
**自动检查项**：
- 人物一致性（称谓、性格）
- 时间线逻辑
- 情节连贯性
- 字数统计

### 9. 导出功能
**导出格式**：
- TXT 纯文本
- Markdown
- Word（可选）
- PDF（可选）

**导出选项**：
- 包含/排除未完成部分
- 自定义导出范围
- 可选附录（角色表、大纲）

## 🏗️ 技术架构

### 技术栈（已确定）
- **前端**：Vue 3 + Element Plus + Monaco Editor + Pinia
- **后端**：Node.js + Express + MongoDB
- **集成方式**：RealWeb 工具模块
- **数据存储**：MongoDB（用户项目数据）

### 核心模块
1. **提示词生成引擎** (`promptTemplates.js`)
2. **AI 回答解析器** (`aiResponseParser.js`)
3. **上下文管理器** (前端状态管理)
4. **导出工具** (`dramaExporter.js`)

## 📐 工作流设计

### 标准创作流程
```
1. 创建项目（设定类型、集数）
   ↓
2. 设定世界观（背景、主题、冲突、基调）
   → 生成提示词 → AI 生成 → 解析填充
   ↓
3. 创建角色（主角、配角、反派）
   → 批量生成提示词 → AI 生成 → 批量导入
   ↓
4. 编写大纲（三幕结构、关键节点）
   → AI 智能生成 → 解析填充
   ↓
5. 创建分集（批量创建框架）
   → 生成提示词 → 逐集完善
   ↓
6. 优化润色
   ↓
7. 导出成品（选择格式、范围）
```

### AI 辅助循环
```
用户输入/编辑
   ↓
系统生成提示词（包含完整上下文）
   ↓
用户复制到 AI 平台
   ↓
AI 生成内容
   ↓
用户粘贴回工具
   ↓
系统智能解析
   ↓
自动填充表单
   ↓
用户审核调整
   ↓
保存到数据库
```

## 🎨 UI/UX 设计原则

### 核心设计理念
1. **简洁直观**：清晰的导航和信息层级
2. **流程导向**：向导模式引导新手
3. **灵活自由**：支持跳转和自定义
4. **即时反馈**：操作即时响应
5. **专业美观**：温暖配色 + 卡片化设计

### 交互特性
- 卡片化布局
- Hover 动画
- 拖拽排序
- 快捷操作
- 智能提示
- 响应式设计

## 📝 已知限制

1. **AI 平台依赖**：需手动复制粘贴，未直连 API
2. **导出格式**：当前仅支持 TXT/Markdown
3. **协作功能**：单人使用，暂不支持多人协作
4. **移动端**：响应式但未专门优化
5. **模板数量**：基础模板较少
