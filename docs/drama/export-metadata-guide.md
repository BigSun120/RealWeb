# 导出创作辅助信息说明

## 概述

从 v1.1 版本开始，导出功能支持选择是否包含**创作辅助信息**（metadata），让用户可以根据不同使用场景选择合适的导出格式。

## 什么是创作辅助信息？

创作辅助信息是指在剧本创作过程中生成的**辅助性数据**，包括：

### 1. 关键对白 (keyDialogues)

**性质：** AI提取的重要台词精华

**示例：**
```
关键对白：
1. "你就是陈氏集团的新总裁？"
2. "有些人，注定是要相遇的。"
3. "我会让你后悔当初的选择。"
```

**作用：**
- 📝 帮助编剧快速定位核心对话
- 🎯 审核时快速了解剧情要点
- 💡 AI生成的台词精华提取
- 🔍 方便搜索和引用

**特点：**
- 从完整剧本中提取
- 类似"笔记"或"标签"
- 不是剧本正文，而是元数据

### 2. 结尾悬念 (cliffhanger)

**性质：** 连续性设计备注

**示例：**
```
结尾悬念：林晓雪意外发现陈默寒手中的照片，那是她已故父亲的模样...
```

**作用：**
- 🔗 记录本集如何引入下一集
- 📋 提醒编剧设计悬念点
- 🎬 指导导演如何处理集尾
- 🎭 确保连续剧的连贯性

**特点：**
- 创作层面的设计意图
- 给创作者的备忘录
- 不一定是最终呈现的台词

### 3. 备注 (notes)

**性质：** 创作过程中的记录

**示例：**
```
备注：本集需要特别注意男主的眼神表现，暗示他已经认出女主身份但故意隐瞒。
```

**作用：**
- 📌 记录创作思路
- 🎨 拍摄和表演提示
- 🔄 后期修改备忘
- 👥 团队协作沟通

## 两种导出模式对比

### 模式A：完整工作版（包含创作辅助信息）

**适用场景：**
- ✅ 内部团队协作
- ✅ 项目备份和归档
- ✅ 编剧修改和审阅
- ✅ 导演和制片人参考

**优点：**
- 信息完整，便于编辑
- 包含创作意图和备注
- 适合工作流程使用
- 方便团队沟通

**示例输出：**
```markdown
## 第1集：相遇

**概要**：男女主角在商业活动中初次相遇...

### 场景1：豪华酒店宴会厅
[剧本正文...]

**关键对白**：
1. "你就是陈氏集团的新总裁？"
2. "有些人，注定是要相遇的。"

**结尾悬念**：林晓雪意外发现陈默寒手中的照片...

*备注*：本集需要特别注意男主的眼神表现...

---
```

### 模式B：纯净剧本版（不包含创作辅助信息）

**适用场景：**
- ✅ 正式对外交付
- ✅ 投资方审核
- ✅ 版权登记
- ✅ 公开发布

**优点：**
- 格式专业标准
- 阅读流畅清晰
- 符合行业规范
- 不泄露创作意图

**示例输出：**
```markdown
## 第1集：相遇

**概要**：男女主角在商业活动中初次相遇...

### 场景1：豪华酒店宴会厅
[剧本正文...]

---
```

## 使用指南

### 在导出对话框中选择

导出时，您会看到以下选项：

```
┌─────────────────────────────────┐
│ 📦 额外内容                      │
├─────────────────────────────────┤
│ ☑️ 包含世界观和角色设定          │
│ ☑️ 包含创作辅助信息 ⓘ           │
└─────────────────────────────────┘
```

**提示信息（鼠标悬停查看）：**
```
包括：
• 关键对白：AI提取的重要台词
• 结尾悬念：连续性设计备注
• 备注：创作过程中的记录

• 勾选：完整工作版（适合内部协作、备份）
• 不勾选：纯净剧本版（适合正式交付、审核）
```

### API 参数

**前端调用：**
```javascript
// 包含创作辅助信息（默认）
exportDramaProject(projectId, {
  format: 'txt',
  includeMetadata: true
});

// 不包含创作辅助信息
exportDramaProject(projectId, {
  format: 'txt',
  includeMetadata: false
});
```

**后端API：**
```bash
# 包含（默认）
GET /api/tools/drama/projects/{id}/export?format=txt

# 不包含
GET /api/tools/drama/projects/{id}/export?format=txt&includeMetadata=false
```

## 最佳实践建议

### 内部工作流程

**推荐：包含创作辅助信息 ✅**

```javascript
exportDramaProject(projectId, {
  format: 'markdown',
  includeMetadata: true,
  includeIncomplete: true
});
```

**原因：**
- 团队协作需要完整信息
- 编辑修改时需要参考备注
- 备份时保留所有创作数据

### 对外交付

**推荐：不包含创作辅助信息 ✅**

```javascript
exportDramaProject(projectId, {
  format: 'txt',
  includeMetadata: false,
  includeIncomplete: false
});
```

**原因：**
- 符合行业标准格式
- 避免泄露创作意图
- 呈现更专业的形象

### 版本控制和备份

**推荐：包含创作辅助信息 ✅**

```javascript
exportDramaProject(projectId, {
  format: 'markdown',
  includeMetadata: true,
  includeIncomplete: true
});
```

**原因：**
- 保留完整的项目信息
- 方便后续恢复和参考
- Markdown 格式适合版本对比

### 投资方和审核方

**推荐：不包含创作辅助信息 ✅**

**原因：**
- 正式、专业的呈现
- 避免过多辅助信息干扰阅读
- 符合审核流程要求

根据《编剧格式手册》和行业标准：

**标准剧本格式包含：**
- ✅ 场景描述
- ✅ 人物对话
- ✅ 动作指示

**标准剧本格式不包含：**
- ❌ 关键对白提取
- ❌ 结尾悬念备注
- ❌ 创作思路记录

- ✅ 包含所有创作辅助信息

**对外版本：**
- ✅ 纯净剧本格式
- ✅ 符合平台审核要求

## 常见问题

### Q1: 默认是包含还是不包含？

**A:** 默认**包含**创作辅助信息。

**理由：**
- 大多数导出是为了工作使用
- 信息完整便于后续操作
- 用户可以自主选择关闭

### Q2: 已导出的文件能去除辅助信息吗？

**A:** 可以。有两种方式：

1. **重新导出**：取消勾选"包含创作辅助信息"
2. **手动编辑**：在文本编辑器中删除相关章节

### Q3: 两种模式文件大小差异大吗？

**A:** 差异不大，通常在 5-15% 左右。

**说明：**
- 创作辅助信息占比较小
- 主要内容是剧本正文
- 对下载和存储影响微小

### Q4: 能否自定义选择包含哪些辅助信息？

**A:** 当前版本暂不支持，计划在后续版本中实现。

**未来规划：**
```
☑️ 包含关键对白
☑️ 包含结尾悬念
☐ 包含备注
```

### Q5: PDF和DOCX导出也支持吗？

**A:** PDF和DOCX导出功能计划在 v1.2 版本实现，届时也会支持此选项。

## 总结

创作辅助信息功能让导出更加灵活，能够满足不同场景的需求：

| 维度 | 包含辅助信息 | 不包含辅助信息 |
|------|-------------|---------------|
| **使用场景** | 内部工作、团队协作 | 正式交付、对外发布 |
| **文件类型** | 完整工作版 | 纯净剧本版 |
| **信息量** | 完整详细 | 精简专业 |
| **适合人群** | 编剧团队、导演 | 投资方、审核方 |

**我们的建议：**
- 🟢 **工作中**：保持默认（包含），便于协作
- 🔵 **交付时**：取消勾选（不包含），更专业
- 🟡 **备份时**：包含所有信息，保留完整数据
