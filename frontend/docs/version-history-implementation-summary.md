## 📊 数据存储设计

### 版本表结构（IndexedDB）
```javascript
{
  id: string,              // 唯一ID
  projectId: string,       // 所属项目
  moduleType: string,      // worldview/character/outline/episode
  moduleId: string,        // 模块ID
  content: object,         // 完整快照（JSON）
  createdAt: timestamp     // 创建时间
}
```

### 索引设计
- `projectId` - 快速查询项目所有版本
- `[projectId+moduleType+moduleId]` - 复合索引，查询特定模块版本

### 存储策略
- 每个模块保留**最新5个版本**
- 完整快照存储（无差异化）
- 深拷贝避免引用污染
- 自动清理旧版本

## 📱 用户操作流程

### 创建版本（自动）
```
1. 用户编辑世界观/角色/大纲/分集
2. 点击"保存"按钮
3. ✅ 数据保存成功
4. ✅ 自动创建版本快照（用户无感知）
5. ✅ 自动清理旧版本（超过5个）
```

### 查看版本
```
1. 点击左侧菜单"版本历史"
2. 看到按日期分组的版本列表
3. 点击版本卡片的"查看"按钮
4. 弹窗显示版本详情
```

### 恢复版本
```
1. 点击版本卡片的"恢复"按钮
2. 确认对话框（显示模块、时间）
3. 点击"确认恢复"
4. ✅ 当前内容被替换
5. ✅ 当前内容自动保存为新版本
6. ✅ 显示成功提示
```

### 删除版本
```
1. 点击版本卡片的"删除"按钮
2. 确认对话框（警告不可撤销）
3. 点击"确认删除"
4. ✅ 版本被删除
5. ✅ 列表自动更新
```

## 📝 使用说明

### 对于用户
1. **正常使用，无需关心**：每次保存时会自动创建版本快照
2. **需要回退时**：打开"版本历史"，找到想要的版本，点击"恢复"
3. **不用担心版本太多**：系统自动保留最新5个，旧版本会被清理

### 对于开发者
1. **版本管理工具**：使用 `versionManager.js` 中的函数
2. **创建版本**：`await createVersion(moduleType, moduleId, content, projectId)`
3. **获取版本**：`await getVersions(projectId)`
4. **恢复版本**：`await restoreVersion(versionId)`
