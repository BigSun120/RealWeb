# 剧本医生功能说明

## 功能概述

剧本医生是AI短剧脚本生成器的智能分析模块，能够自动分析剧本的结构完整性、检测常见问题，并提供优化建议。

## 功能特点

### 1. 基础统计分析
- **字数统计**：分析世界观、角色、大纲、分集的字数
- **数量统计**：统计角色数量、集数、完成进度等
- **角色分析**：区分主角和配角，分析角色分布

### 2. 结构完整性检测
- **世界观完整性**：检查背景、设定、主题、冲突、基调等要素
- **角色完整性**：评估角色设定的完整程度
- **大纲完整性**：分析剧情大纲的结构和节点数量
- **分集进度**：追踪分集剧本的完成情况

### 3. 问题检测（15+规则）
#### 严重问题（Critical）
- 角色名重复
- 缺少主角
- 缺少剧情节点

#### 警告（Warning）
- 角色名相似可能混淆
- 角色性格描述过短
- 大纲幕次缺少节点
- 分集内容过短
- 世界观字段缺失

#### 提示（Info）
- 剧情节点较少
- 分集内容较长
- 角色未在大纲中出现
- 世界观描述过短

### 4. 智能优化建议
根据分析结果自动生成优化建议，包括：
- 基于完整性评分的改进建议
- 基于统计数据的内容建议
- 基于剧本类型的特征建议
- 节奏和长度控制建议

## 技术实现

### 核心文件
1. **analysisEngine.js**：分析引擎
   - `analyzeBasicStats()`：基础统计
   - `analyzeCompleteness()`：完整性分析
   - `detectIssues()`：问题检测
   - `generateSuggestions()`：建议生成

2. **ScriptAnalysis.vue**：UI组件
   - 整体评估卡片
   - 问题检测标签页
   - 统计图表展示
   - 优化建议列表

3. **workbench.vue**：工作台集成
   - 新增"剧本医生"菜单项
   - 传递完整项目数据
   - 支持跨模块跳转

## 使用方式

1. 在剧本工作台左侧导航栏点击"剧本医生"
2. 系统自动分析当前项目
3. 查看整体评估、问题检测、统计数据
4. 根据建议点击"前往处理"按钮跳转到相关模块
5. 可随时点击"重新分析"刷新结果

## UI界面说明

### 整体评估区
- 圆形进度条显示完整性得分
- 总字数、角色数量、完成集数等关键指标

### 问题检测区
- 三个标签页：严重问题、警告、提示
- 每个问题显示标题、描述和处理按钮
- 使用不同颜色区分问题级别

### 统计区
- 左侧：各模块字数统计
- 右侧：各模块完整性进度条

### 建议区
- 按优先级排序的优化建议
- 带标签显示紧急程度
- 可直接跳转到相关模块

## 评分标准

### 完整性评分
- 80-100分：优秀（绿色）
- 60-79分：良好（橙色）
- 40-59分：需改进（红色）
- 0-39分：严重不足（灰色）

### 加权计算
- 世界观：20%
- 角色：20%
- 大纲：30%
- 分集：30%
