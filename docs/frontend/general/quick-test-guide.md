# 快速测试指南

## 🎯 核心测试场景

### 场景1：自动保存分类测试 ⭐
**目标**：验证自动保存版本在版本历史中正确分类

**步骤**：
1. 打开一个剧本项目
2. 修改世界观或角色内容（不要手动保存）
3. 等待1小时或在控制台手动触发：`performAutoSave()`
4. 打开版本历史
5. 点击"自动保存"标签
   - ✅ 应该看到刚才自动保存的版本
   - ✅ 版本项应该有"自动"标签
6. 点击"手动保存"标签
   - ✅ 不应该包含刚才的自动保存版本
7. 点击"全部"标签
   - ✅ 应该同时看到手动和自动保存的版本

**快速触发自动保存**（开发测试用）：
```javascript
// 在浏览器控制台执行
// 方法1：直接调用（如果暴露了方法）
performAutoSave()

// 方法2：修改自动保存间隔为10秒
autoSaveInterval = 10000
startAutoSaveTimer()
// 然后修改内容，等待10秒
```

---

### 场景2：空分集不触发警告 ⭐
**目标**：验证空分集不会误报"内容过短"

**步骤**：
1. 创建新项目
2. 填写基本的世界观和角色
3. 不添加任何分集内容（或创建空分集）
4. 打开"剧本医生"
5. 查看"问题检测"区域
   - ✅ 不应该有"分集内容过短"的警告
   - ✅ 可能有"缺少剧情节点"等其他提示

---

### 场景3：情感基调字段检测 ⭐
**目标**：验证情感基调使用10字阈值

**步骤**：
1. 世界观 → 情感基调
2. 输入"轻松"（2字）→ 保存 → 打开剧本医生
   - ✅ 应该有提示："情感基调"描述过短
3. 修改为"轻松幽默"（4字）→ 保存 → 刷新分析
   - ✅ 仍然有提示
4. 修改为"轻松幽默、甜蜜温馨"（10字）→ 保存 → 刷新分析
   - ✅ 不应该再有提示

---

### 场景4：其他世界观字段检测
**目标**：验证其他字段使用30字阈值

**步骤**：
1. 世界观 → 故事背景
2. 输入20字内容 → 保存 → 打开剧本医生
   - ✅ 应该有提示："故事背景"描述过短
3. 修改为30字以上 → 保存 → 刷新分析
   - ✅ 不应该再有提示

---

### 场景5：角色性格检测
**目标**：验证角色性格使用30字阈值

**步骤**：
1. 角色管理 → 创建角色
2. 性格输入20字 → 保存 → 打开剧本医生
   - ✅ 应该有警告："角色性格描述过短"
3. 修改为30字以上 → 保存 → 刷新分析
   - ✅ 不应该再有警告

---

### 场景6：分集内容长度检测
**目标**：验证分集字数阈值调整

**步骤**：
1. 分集剧本 → 创建一集
2. 输入500字内容 → 保存 → 打开剧本医生
   - ✅ 应该有警告："分集内容过短"（< 800字）
3. 补充到800字以上 → 保存 → 刷新分析
   - ✅ 不应该再有警告
4. 继续补充到2600字 → 保存 → 刷新分析
   - ✅ 应该有提示："分集内容较长"（> 2500字）

---

### 场景7：菜单顺序验证
**目标**：验证工作台菜单顺序符合逻辑

**步骤**：
1. 打开任意剧本项目
2. 查看左侧菜单栏
3. 验证顺序：
   - ✅ 1-4：世界观、角色、大纲、分集（创作流程）
   - ✅ 5-6：剧本医生、数据统计（分析工具）
   - ✅ 7-8：提示词模板、版本历史（辅助功能）

## 🚨 注意事项

1. 自动保存默认1小时间隔，测试时可以修改代码临时缩短
2. 版本历史的筛选是纯前端逻辑，不涉及后端
3. 剧本医生的分析是实时计算，不缓存结果
4. 字数统计包含中英文，标点符号也计入
