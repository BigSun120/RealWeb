# 前端导出功能实现文档

## 概述

已完成短剧脚本生成器的前端导出功能，包括项目列表页和工作台两个位置的导出功能，提供灵活的导出选项和友好的用户体验。

## 实现内容

### 1. 新增文件

#### `frontend/src/utils/download.js`
通用文件下载工具函数：
- `downloadBlob(blob, filename)` - 下载 Blob 文件
- `generateFilename(baseName, extension)` - 生成带时间戳的文件名
- `downloadText(content, filename, mimeType)` - 下载文本内容

#### `frontend/src/views/tools/productivity/drama/components/ExportDialog.vue`
导出对话框组件：
- 显示项目完整性状态（已完成/进行中/草稿集数）
- 导出格式选择（TXT/Markdown）
- 导出范围选择（仅已完成/包含未完成/自定义范围）
- 额外内容选项（包含世界观和角色设定）
- 导出预览信息
- 智能提示和验证

### 2. 修改文件

#### `frontend/src/views/tools/productivity/drama/index.vue`
项目列表页导出功能：
- 导入 `ExportDialog` 组件和工具函数
- 添加导出对话框状态管理
- 实现 `handleExportProject()` - 获取完整项目数据并打开对话框
- 实现 `handleConfirmExport()` - 处理导出确认并下载文件
- 在模板中添加 `<ExportDialog>` 组件

#### `frontend/src/views/tools/productivity/drama/workbench.vue`
工作台快速导出功能：
- 将导出按钮改为下拉分割按钮
- 提供快速导出选项：
  - 主按钮：快速导出TXT（仅已完成）
  - 下拉菜单：导出TXT、导出Markdown、包含未完成剧集、自定义导出
- 实现 `handleQuickExport()` - 快速导出
- 实现 `handleExportCommand()` - 处理下拉菜单命令
- 实现 `performExport()` - 执行导出逻辑
- 实现 `handleConfirmExport()` - 处理对话框导出
- 添加 `exportProjectData` 计算属性
- 在模板中添加 `<ExportDialog>` 组件

## 功能特性

### 列表页导出（智能导出）

**触发位置：**
- 项目卡片的下拉菜单 → 导出
- 列表视图的操作列 → 导出

**交互流程：**
1. 点击导出按钮
2. 后台获取完整项目数据
3. 弹出导出对话框
4. 显示项目完整性状态
5. 用户选择导出选项
6. 确认导出并下载文件

**适用场景：**
- 用户在浏览多个项目时
- 不清楚项目完成度
- 需要灵活选择导出内容

### 工作台导出（快速导出）

**触发位置：**
- 顶部导航栏的导出下拉按钮

**交互流程：**

**方式一：快速导出**
1. 点击导出按钮主体
2. 直接导出TXT格式（仅已完成剧集）
3. 自动下载文件

**方式二：选择格式导出**
1. 点击下拉箭头
2. 选择 "导出TXT" 或 "导出Markdown"
3. 自动导出并下载

**方式三：包含未完成**
1. 点击下拉箭头
2. 选择 "包含未完成剧集"
3. 导出TXT格式（包含所有剧集）

**方式四：自定义导出**
1. 点击下拉箭头
2. 选择 "自定义导出..."
3. 弹出导出对话框
4. 详细配置导出选项
5. 确认导出并下载

**适用场景：**
- 用户正在编辑项目
- 熟悉项目状态
- 需要快速导出当前版本

## 导出对话框功能详解

### 项目完成情况

显示剧集状态统计：
```
✅ 已完成：12集
⏳ 进行中：3集
📝 草稿：2集
```

**智能提示：**
- 如果没有已完成剧集，显示警告提示
- 自动建议勾选"包含未完成剧集"选项

### 导出格式

- **TXT 纯文本**：通用文本格式，兼容性好
- **Markdown**：富文本格式，适合文档化和版本管理

### 导出范围

- **仅已完成**：只导出状态为"已完成"或"已审核"的剧集
- **包含未完成**：导出所有剧集（包括草稿和进行中）
- **自定义范围**：指定导出前N集

**自定义范围示例：**
```
截止集数：[10]
说明：导出第 1 集到第 10 集
```

### 额外内容

- **包含世界观和角色设定**
  - 如果项目有世界观或角色设定，可选择包含
  - 如果没有设定，选项被禁用并提示

### 导出预览

实时显示将要导出的内容：
```
🔍 将导出 12 集剧本，包含世界观和角色设定
```

### 按钮状态

- **取消按钮**：关闭对话框
- **确认导出按钮**：
  - 正常状态：显示"确认导出"
  - 导出中：显示"导出中..."并禁用
  - 无内容可导出时：按钮被禁用

## 文件命名规则

生成的文件名格式：
```
{项目名称}_{时间戳}.{扩展名}

示例：
霸道总裁的百日契约_2025-10-13T09-44-00.txt
甜宠日常小剧场_2025-10-13T09-44-00.md
```

**特点：**
- 自动清理文件名中的非法字符
- 添加ISO格式时间戳（便于版本管理）
- 根据格式自动选择扩展名（txt/md）

## 技术细节

### 数据流

**列表页：**
```
用户点击导出
  ↓
调用 getDramaProject(id) 获取完整数据
  ↓
存储到 currentExportProjectData
  ↓
打开 ExportDialog
  ↓
用户配置选项
  ↓
调用 exportDramaProject(id, options)
  ↓
下载 Blob 文件
```

**工作台：**
```
用户选择导出方式
  ↓
快速导出 或 打开对话框
  ↓
使用内存中的 exportProjectData
  ↓
调用 exportDramaProject(id, options)
  ↓
下载 Blob 文件
```

### 关键代码片段

**文件下载：**
```javascript
import { downloadBlob, generateFilename } from '@/utils/download';

const blob = await exportDramaProject(projectId, options);
const ext = options.format === 'markdown' ? 'md' : 'txt';
const filename = generateFilename(projectName, ext);
downloadBlob(blob, filename);
```

**导出对话框：**
```vue
<ExportDialog
  ref="exportDialogRef"
  v-model="exportDialogVisible"
  :project-id="projectId"
  :project-name="projectName"
  :project-data="projectData"
  @confirm="handleConfirmExport"
/>
```
