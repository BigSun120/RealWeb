## 🔀 阶段自适应机制

### 阶段判定逻辑

系统根据项目当前状态自动识别应处于哪个诊断阶段：

```javascript
function determineStage(project) {
  // 1. 检查前期准备完成度
  const preparationScore = calculatePreparationScore(project);
  const preparationReady = preparationScore >= 75;
  
  // 2. 检查分集创作进度
  const completedEpisodes = getCompletedEpisodes(project);
  const totalEpisodes = project.episodeCount || 60;
  const progress = completedEpisodes / totalEpisodes;
  
  // 3. 阶段判定
  if (!preparationReady) {
    return {
      stage: 1,
      name: '前期准备',
      icon: '📝',
      color: '#409EFF',
      description: '完善世界观、角色、大纲',
      nextStageRequirement: '准备就绪度达到75分'
    };
  } else if (progress < 0.8) {
    return {
      stage: 2,
      name: '分集质量',
      icon: '📺',
      color: '#67C23A',
      description: '逐集检查质量，及时优化',
      nextStageRequirement: '完成80%分集创作'
    };
  } else {
    return {
      stage: 3,
      name: '整体优化',
      icon: '🎬',
      color: '#E6A23C',
      description: '全剧连贯性与商业价值分析',
      nextStageRequirement: '最终发布前优化'
    };
  }
}
```

## 🔄 双诊断模式架构

### 模式对比

| 维度 | 快速诊断 | AI深度诊断 |
|------|----------|-----------|
| **技术实现** | 纯前端规则引擎 | 调用AI API |
| **数据来源** | 本地项目数据 | 本地数据 + AI推理 |
| **计算位置** | 浏览器端 | 服务器端（AI） |
| **响应时间** | 2-5秒 | 30-60秒 |
| **成本** | 零成本 | 消耗Token（约0.1-0.5元/次） |
| **准确度** | 规则覆盖的问题 | 更全面、更深入 |
| **创意性** | 无 | 可提供创意建议 |
| **适用场景** | 日常检查、快速迭代 | 关键节点、深度优化 |

### 模式选择流程

```
用户点击诊断
      ↓
┌─────────────┐
│ 选择诊断模式 │
└─────────────┘
      ↓
   分支判断
      ├─────────────────┐
      ↓                 ↓
┌─────────────┐   ┌─────────────┐
│ 快速诊断    │   │ AI深度诊断  │
└─────────────┘   └─────────────┘
      ↓                 ↓
本地规则引擎      生成提示词
      ↓                 ↓
即时返回结果      调用AI API
                        ↓
                   解析AI响应
                        ↓
                   结构化展示
```

## 🔌 接口设计

### 快速诊断接口

```javascript
/**
 * 快速诊断（本地）
 * @param {Object} project - 项目数据
 * @param {Number} stage - 诊断阶段 (1/2/3)
 * @returns {Object} 诊断结果
 */
function quickDiagnosis(project, stage) {
  // 1. 数据统计
  const stats = analyzeBasicStats(project);
  
  // 2. 完整性分析
  const completeness = analyzeCompleteness(project);
  
  // 3. 问题检测
  const issues = detectIssues(project, stage);
  
  // 4. 建议生成
  const suggestions = generateSuggestions(project, stats, completeness, issues);
  
  // 5. 评分计算
  const scores = calculateScores(completeness, stats);
  
  // 6. 组装结果
  return {
    timestamp: new Date().toISOString(),
    stage,
    mode: 'quick',
    overallScore: scores.overall,
    scores,
    stats,
    issues,
    suggestions
  };
}
```

### AI诊断接口

```javascript
/**
 * AI深度诊断
 * @param {Object} project - 项目数据
 * @param {Number} stage - 诊断阶段 (1/2/3)
 * @returns {Promise<Object>} 诊断结果
 */
async function aiDiagnosis(project, stage) {
  // 1. 生成提示词
  const prompt = generateDiagnosisPrompt(project, stage);
  
  // 2. 调用AI API
  const aiResponse = await callAIAPI(prompt);
  
  // 3. 解析AI响应
  const aiAnalysis = parseAIResponse(aiResponse);
  
  // 4. 结合本地分析
  const localResult = quickDiagnosis(project, stage);
  
  // 5. 融合结果
  return {
    ...localResult,
    mode: 'ai',
    aiAnalysis,
    prompt  // 保存提示词供调试
  };
}
```

### 提示词生成接口

```javascript
/**
 * 生成诊断提示词（用于外部AI）
 * @param {Object} project - 项目数据
 * @param {Number} stage - 诊断阶段 (1/2/3)
 * @returns {String} 格式化的提示词
 */
function generateDiagnosisPrompt(project, stage) {
  switch(stage) {
    case 1:
      return generatePreparationPrompt(project);
    case 2:
      return generateEpisodePrompt(project);
    case 3:
      return generateOverallPrompt(project);
    default:
      throw new Error('Invalid stage');
  }
}
```

## 🔐 安全与性能

### 数据安全
- 本地诊断数据不上传服务器
- AI诊断时脱敏敏感信息
- 诊断历史仅存储在本地

### 性能优化
- 快速诊断结果缓存（5分钟）
- AI诊断防抖（避免重复调用）
- 大数据量分页处理（分集列表）
- 统计数据增量计算

### 错误处理
```javascript
try {
  const result = await aiDiagnosis(project, stage);
  // 成功处理
} catch (error) {
  if (error.code === 'AI_API_ERROR') {
    // AI API错误，降级到快速诊断
    const fallbackResult = quickDiagnosis(project, stage);
    // 提示用户
  } else if (error.code === 'NETWORK_ERROR') {
    // 网络错误，提示重试
  } else {
    // 其他错误，记录日志
  }
}
```
