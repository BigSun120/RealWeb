# 功能清单-03-内容管理

> **模块说明**: 本模块负责角色、大纲、剧本的存储、编辑和版本管理

---

## 1. 角色库管理

### 1.1 角色CRUD 【P0】
- **创建角色**: 手动录入或AI生成后导入
- **编辑角色**: 修改姓名/年龄/性格等所有字段
- **删除角色**: 支持软删除（可恢复）
- **角色列表**: 卡片/列表双视图

### 1.2 角色卡片展示 【P0】
```
┌─────────────────┐
│  [头像/图标]    │
│  李雨晴         │
│  女主角 | 25岁  │
│  设计师         │
│  ─────────────  │
│  独立·善良·倔强 │
│  [编辑] [详情]  │
└─────────────────┘
```

**字段**:
- 基础: 姓名、性别、年龄、职业
- 进阶: 性格标签、背景故事、目标动机
- 关系: 与其他角色的关系链

### 1.3 角色关系管理 【P1】
- **关系类型**: 亲人/朋友/恋人/敌对/竞争/上下级
- **关系描述**: 文字说明关系细节
- **双向关系**: A→B时自动创建B→A
- **关系图谱**（可选P2）: 可视化展示人物关系网

### 1.4 角色搜索与筛选 【P1】
- 按角色类型（主角/配角/反派）
- 按性别、年龄范围
- 关键词搜索（姓名、性格）

---

## 2. 大纲管理

### 2.1 大纲结构化存储 【P0】
**层级结构**:
```
大纲
├─ 第一幕（1-10集）
│  ├─ 第一章: 相遇
│  │  ├─ 情节点1: 女主入职
│  │  └─ 情节点2: 初次碰撞
│  └─ 第二章: 误会
├─ 第二幕（11-20集）
└─ 第三幕（21-30集）
```

### 2.2 大纲可视化编辑 【P0】
- **树形展示**: 折叠/展开任意层级
- **拖拽排序**: 调整幕/章/节顺序
- **快速编辑**: 双击进入编辑模式
- **标记状态**: 未开始/进行中/已完成

### 2.3 关键情节点管理 【P1】
- **情节点列表**: 独立展示所有关键转折
- **集数关联**: 标记情节发生在第几集
- **类型标签**: 初遇/反转/高潮/结局等
- **完成追踪**: 是否已写入剧本

### 2.4 大纲导出与打印 【P1】
- Markdown格式
- 分幕导出（只导出特定幕）
- 打印友好格式

## 3. 剧本管理

### 3.1 剧本组织结构 【P0】
```
项目
└─ 剧本
   ├─ 第1集
   │  ├─ 场景1: 日/外/公司门口
   │  │  ├─ 场景描述
   │  │  ├─ 对白1: 李雨晴说...
   │  │  └─ 动作: 李雨晴推门进入
   │  ├─ 场景2: ...
   │  └─ 场景3: ...
   ├─ 第2集
   └─ ...
```

### 3.2 剧本编辑器 【P0】
**核心功能**:
- **所见即所得**: Markdown编辑
- **场景标注**: 【场景X：时间/内外/地点】自动识别
- **角色对白**: 自动高亮角色名
- **动作描述**: 括号内容自动斜体
- **实时字数**: 每场景/每集/总字数统计

**格式模板**:
```
【场景1：日/外/咖啡厅】

（镜头推向窗边位置，李雨晴独自坐着看手机）

李雨晴：（自言自语）今天是第一天，一定要好好表现。

（陈墨突然出现在门口，目光扫视全场）

陈墨：（冷淡）你就是新来的设计师？

李雨晴：（站起身，微笑）是的，陈总好。
```

### 3.3 快速导航 【P0】
- **集数列表**: 左侧边栏显示所有集数
- **场景列表**: 点击集数展开场景
- **跳转**: 点击场景直接定位
- **搜索**: 全文搜索对白/场景

### 3.4 剧本对比 【P1】
- **版本对比**: 并排显示两个版本
- **差异高亮**: 新增/删除/修改用不同颜色
- **逐行对比**: 精确到每一句对白

### 3.5 批注与备忘 【P1】
- **行内批注**: 选中文本添加批注
- **段落备忘**: 为场景添加创作思路
- **待办标记**: 标记需要修改的地方
- **协作批注**（P3）: 多人协作时使用

## 4. 版本控制

### 4.1 自动版本保存 【P1】
**触发条件**:
- 手动保存（Ctrl+S）
- 定时自动保存（每3分钟）
- 关键操作后（生成新内容/大量编辑）

**版本信息**:
```json
{
  "versionId": "v_001",
  "timestamp": "2025-10-12 14:30:00",
  "description": "完成第1-5集初稿",
  "type": "auto",  // auto | manual
  "changes": "+1200字，新增3个场景",
  "author": "用户A"
}
```

### 4.2 版本列表与管理 【P1】
**显示**:
```
版本历史（第1集）

📌 v5 - 当前版本
   2025-10-12 14:30
   完成对白润色 (+300字)
   [查看] [回滚]

   v4
   2025-10-12 12:00
   初稿完成
   [查看] [对比] [回滚]

   v3
   2025-10-11 18:00
   场景结构调整
   [查看] [对比]
```

**操作**:
- **查看**: 只读模式查看历史版本
- **对比**: 与当前版本对比
- **回滚**: 恢复到该版本（当前版本自动保存）
- **删除**: 删除历史版本（保留最近10个版本不可删）

### 4.3 版本分支 【P2】
- **创建分支**: 从当前版本创建实验分支
- **分支列表**: 主线/分支A/分支B
- **切换分支**: 在不同分支间切换
- **合并分支**: 将分支内容合并回主线

**使用场景**:
```
主线: 第1-30集正式剧本
分支A: 尝试不同的结局
分支B: 增加悬疑元素的版本
```

### 4.4 版本标签 【P1】
- **里程碑标签**: v1.0初稿、v2.0二审稿、v3.0终稿
- **快速定位**: 通过标签快速找到关键版本
- **标签说明**: 为标签添加详细说明

## 5. 内容统计分析

### 5.1 基础统计 【P1】
**字数统计**:
- 总字数、各集字数
- 对白字数 vs 描述字数
- 字数趋势图（各集字数分布）

**场景统计**:
- 总场景数、各集场景数
- 场景类型分布（日/夜、内/外）
- 平均场景长度

**角色统计**:
- 出场频率（各角色出现在多少集）
- 对白量统计（各角色对白字数）
- 角色出场时间线

### 5.2 质量分析 【P2】
- **节奏分析**: 情节密度曲线（事件数/集）
- **情感曲线**: 各集情感强度（需要标注）
- **冲突点分布**: 冲突是否分布均匀
- **对白/描述比**: 过多对白或描述的提示
