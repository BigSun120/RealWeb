# 功能清单-01-项目与工作流

> **模块说明**: 本模块涵盖项目管理、向导模式和自由创作模式的所有功能点

---

## 1. 项目管理模块

### 1.1 项目CRUD操作

#### 1.1.1 创建新项目 【P0】
**功能描述**: 用户可以创建一个全新的短剧项目

**输入**:
- 项目名称（必填，1-50字符）
- 项目类型（必选，下拉选择）
- 集数（必填，1-100集）
- 每集时长（必填，0.5-5分钟）
- 目标受众（可选，多选：青年/中年/女性/男性等）
- 项目简介（可选，最多200字）

**输出**:
- 生成唯一项目ID
- 初始化项目数据结构
- 创建默认的空白模块（角色库、大纲、剧本列表）
- 跳转到项目详情页或向导第一步

**技术要点**:
- 使用UUID生成项目ID
- IndexedDB存储项目数据
- 验证输入合法性（字符长度、数值范围）
- 防止重名项目（可以重名但需提示）

**验收标准**:
- [ ] 可以成功创建项目并保存到本地
- [ ] 输入验证正确（必填项、格式校验）
- [ ] 创建后立即可见于项目列表
- [ ] 数据持久化，刷新页面不丢失

**测试用例**:
```
TC-1.1.1-01: 正常创建
- 输入: 名称="霸道总裁追妻记", 类型="霸道总裁", 集数=30, 时长=1
- 预期: 创建成功，项目列表显示新项目

TC-1.1.1-02: 必填项校验
- 输入: 名称为空
- 预期: 提示"项目名称不能为空"

TC-1.1.1-03: 边界值测试
- 输入: 集数=0
- 预期: 提示"集数必须大于0"
```

#### 1.1.2 编辑项目信息 【P0】
**功能描述**: 修改已创建项目的基础信息

**输入**:
- 项目ID（系统自动识别）
- 可修改字段：名称、类型、集数、时长、目标受众、简介

**输出**:
- 更新项目信息
- 更新"最后修改时间"
- 显示保存成功提示

**技术要点**:
- 深拷贝修改，避免直接修改原对象
- 修改集数时需检查是否有超出范围的已创建剧本
- 记录修改历史（可选）

**验收标准**:
- [ ] 可以单独修改任意字段
- [ ] 修改后立即生效
- [ ] 如果修改集数小于已有剧本数，给出警告
- [ ] 时间戳正确更新

---

#### 1.1.3 删除项目 【P0】
**功能描述**: 删除整个项目及所有相关数据

**输入**:
- 项目ID

**输出**:
- 删除项目及所有子数据（角色、大纲、剧本、版本等）
- 从列表中移除
- 显示删除成功提示

**技术要点**:
- 二次确认弹窗（防误删）
- 级联删除所有关联数据
- 考虑添加"回收站"功能（P2阶段）

**验收标准**:
- [ ] 删除前有明确的确认提示
- [ ] 删除后数据完全清除
- [ ] 列表实时更新
- [ ] 无法撤销（或有回收站）

**测试用例**:
```
TC-1.1.3-01: 正常删除
- 操作: 删除项目A
- 预期: 确认弹窗 → 确认 → 项目A消失

TC-1.1.3-02: 取消删除
- 操作: 删除项目A → 取消
- 预期: 项目A仍然存在
```

### 1.3 项目状态管理

#### 1.3.1 进度自动计算 【P0】
**功能描述**: 根据完成的工作自动计算项目进度

**计算规则**:
```
进度 = (完成步骤数 / 总步骤数) × 100%

步骤权重:
- 基础设定: 10%
- 角色设计: 15%
- 剧情大纲: 20%
- 分集梗概: 15%
- 详细剧本: 35%
- 优化润色: 5%
```

**输出**:
- 百分比数值（0-100）
- 进度条可视化
- 当前阶段标签

**技术要点**:
- 实时计算，无需手动触发
- 缓存计算结果，避免重复计算

**验收标准**:
- [ ] 进度计算准确
- [ ] 实时更新
- [ ] 不同阶段显示对应标签

---

#### 1.3.2 项目状态标识 【P1】
**功能描述**: 清晰标识项目当前所处阶段

**状态类型**:

- 🔵 剧本中（51-90%）
- 🟢 已完成（91-100%）

**显示位置**:
- 项目卡片角标
- 项目详情页顶部
- 编辑页面面包屑

**验收标准**:
- [ ] 状态与进度对应准确

- [ ] 多处显示一致

## 2. 推荐工作流（向导模式）

### 2.1 向导核心框架

#### 2.1.1 向导步骤导航 【P0】
**功能描述**: 顶部步骤条，展示7步流程和当前位置

**显示内容**:
```
[1.基础设定] → [2.角色设计] → [3.剧情大纲] → [4.分集梗概] 
→ [5.详细剧本] → [6.优化润色] → [7.导出成品]
```

**交互**:
- 当前步骤高亮
- 已完成步骤显示✓
- 未完成步骤灰色
- 点击已完成步骤可跳转（可配置是否允许）

**技术要点**:
- 使用Steps组件（Ant Design / Element）
- 状态存储在项目数据中
- 支持前进/后退/跳过

**验收标准**:
- [ ] 步骤条清晰展示流程
- [ ] 当前位置明确标识
- [ ] 跳转逻辑正确

---

#### 2.1.2 步骤间导航控制 【P0】
**功能描述**: 底部导航按钮

**按钮类型**:
- **上一步**: 返回前一步（保留当前步骤数据）
- **下一步**: 进入下一步（需验证当前步骤是否完成）
- **跳过**: 跳过当前步骤（给出警告）
- **保存草稿**: 保存当前进度，不进入下一步

**逻辑规则**:
- 第1步：隐藏"上一步"
- 第7步："下一步"变为"完成"
- 未填写必填项时，"下一步"禁用或提示

**验收标准**:
- [ ] 按钮显示/隐藏逻辑正确
- [ ] 导航不会丢失数据
- [ ] 跳过步骤有明确提示

### 2.2 Step 1: 基础设定

#### 2.2.1 项目基础信息表单 【P0】
**功能描述**: 填写或确认项目基本信息

**表单字段**:
- 项目名称（已填写，可修改）
- 项目类型（已选择，可修改）
- 集数（已填写，可修改）
- 每集时长（已填写，可修改）
- **核心冲突**（新增，必填，200字）：例如"富家女隐瞒身份进入贫穷男主家族企业，身份揭露后的爱恨纠葛"
- **情感基调**（新增，必选）：轻松/虐心/爽剧/温馨/悬疑
- **特殊要求**（可选，500字）：例如"需要包含商战元素""女主要有特殊技能"

**输出**:
- 保存到项目设定模块
- 自动生成"项目设定提示词"

**提示词模板示例**:
```
请为以下短剧项目提供专业的创作建议：

【项目信息】
- 类型：{{项目类型}}
- 集数：{{集数}}集，每集{{时长}}分钟
- 情感基调：{{情感基调}}

【核心冲突】
{{核心冲突}}

【特殊要求】
{{特殊要求}}

请帮我：
1. 分析这个项目的可行性和吸引力
2. 提供创作方向建议
3. 指出可能的创作难点
4. 给出类似成功案例参考
```

**验收标准**:
- [ ] 所有字段正常保存
- [ ] 提示词正确生成
- [ ] 可以一键复制提示词

### 2.3 Step 2: 角色设计

#### 2.3.1 角色需求配置 【P0】
**功能描述**: 配置需要生成的角色数量和类型

**配置项**:
- 主角数量：1-3人（单选：1/2/3）
- 主角性别：男/女/男+女
- 配角数量：0-10人（滑块选择）
- 反派设置：无/弱反派/强反派
- 其他角色：是否需要工具人/氛围组

**输出**:
- 角色生成提示词

**提示词示例**:
```
请基于以下信息设计短剧角色：

【项目背景】
类型：{{项目类型}}
核心冲突：{{核心冲突}}
情感基调：{{情感基调}}

【角色需求】
- 主角：{{主角数量}}人（{{主角性别}}）
- 配角：{{配角数量}}人
- 反派：{{反派设置}}

【角色设计要求】
1. 每个角色需要包含：
   - 姓名（符合类型风格）
   - 年龄、职业
   - 性格特点（3-5个关键词）
   - 背景故事（100字以内）
   - 核心目标/动机
   - 与其他角色的关系

2. 角色需要有鲜明反差和冲突点
3. 符合{{项目类型}}类型的角色设定惯例

请输出完整的角色卡。
```

**验收标准**:
- [ ] 配置项可灵活调整
- [ ] 提示词自动注入项目背景
- [ ] 生成的提示词在AI平台可直接使用

#### 2.3.2 角色卡保存与编辑 【P0】
**功能描述**: 将AI生成的角色信息保存到角色库

**操作流程**:
1. 用户复制提示词到AI平台
2. AI返回角色设定
3. 用户粘贴回工具
4. 工具自动解析（或手动录入）
5. 保存到角色库

**数据结构**:
```json
{
  "id": "char_001",
  "name": "李雨晴",
  "role": "女主角",
  "age": 25,
  "occupation": "设计师",
  "personality": ["独立", "善良", "倔强"],
  "background": "出身富裕家族...",
  "goal": "证明自己的能力",
  "relationships": [
    {"charId": "char_002", "relation": "暧昧对象"}
  ]
}
```

**验收标准**:
- [ ] 支持粘贴文本自动解析（识别"姓名：""性格："等关键词）
- [ ] 支持手动表单录入
- [ ] 角色卡可以编辑
- [ ] 角色之间可以建立关系

### 2.5 Step 4: 分集梗概

#### 2.5.1 批量生成分集梗概 【P0】

**配置项**:
- 生成范围：第X集 - 第Y集（默认1-10）
- 每集梗概长度：简短（3句）/标准（5句）/详细（8句）

**提示词示例**:
```
请为短剧《{{项目名称}}》生成第{{开始集}}-{{结束集}}集的分集梗概。

【大纲参考】
{{相关幕次大纲}}

【生成要求】

   - 情感变化（1句）

2. 确保每集之间逻辑连贯
3. 保持节奏合理，避免拖沓

【输出格式】
第X集：【标题】
- 核心事件：...
- 情感变化：...
- 冲突点：...
- 结尾钩子：...
```

**验收标准**:
- [ ] 可以分批次生成（每次最多10集）
- [ ] 提示词自动加载对应大纲部分
- [ ] 支持重新生成特定集数

### 2.6 Step 5: 详细剧本

#### 2.6.1 剧本分包生成策略 【P0】
**功能描述**: 将剧本生成任务智能拆分

**拆分规则**:
- 默认每次生成3-5集
- 超过用户设置的平台字数限制时自动拆包
- 每个包的提示词独立、自包含

**配置项**:
- 目标平台：ChatGPT（8000字）/Claude（20000字）/自定义
- 每包集数：3/4/5
- 是否包含前情提要：是/否

**提示词示例**:
```
请为短剧《{{项目名称}}》创作第{{X}}-{{Y}}集的详细剧本。

【项目背景】
类型：{{项目类型}}
情感基调：{{情感基调}}

【主要角色】
{{角色卡摘要}}

【前情提要】（第X-1集）
{{上一集摘要}}

【本批次梗概】
第X集：{{梗概}}
第X+1集：{{梗概}}
...

【剧本要求】
1. 每集包含3-5个场景
2. 每场景格式：
   【场景X：时间/地点】
   （场景描述）
   角色A：对白内容
   （动作/情绪描述）
   
3. 对白要生动自然，符合角色人设
4. 场景转换要流畅
5. 每集结尾要有钩子

请开始创作。
```

**验收标准**:
- [ ] 自动拆分提示词
- [ ] 每个提示词不超过平台限制
- [ ] 包含足够的上下文信息
- [ ] 生成顺序提示（如"这是第1/3包"）

### 2.7 Step 6: 优化润色

#### 2.7.1 选择优化目标 【P1】
**功能描述**: 对已完成的剧本进行优化

**优化类型**:
- [ ] 对白打磨（更口语化/更文学化）
- [ ] 情感深化（增强情绪表达）
- [ ] 节奏调整（加快/减慢）
- [ ] 冲突强化（增加戏剧张力）
- [ ] 细节丰富（场景描写）

**选择范围**:
- 全部剧本
- 特定几集
- 特定场景

**提示词示例**:
```
请对以下剧本片段进行{{优化类型}}优化：

【原始剧本】
{{剧本内容}}

【优化方向】
{{具体要求}}

【注意事项】
1. 保持角色人设一致
2. 不改变核心情节
3. 优化后长度控制在原文的80%-120%
```

**验收标准**:
- [ ] 可以多选优化类型
