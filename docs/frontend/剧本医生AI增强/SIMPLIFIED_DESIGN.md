# 剧本医生 - 简化设计方案

> **设计理念**：简单、直观、不打断创作流程

## 🎯 核心目标

- ✅ **能创作**：检查是否具备开始创作的基本条件
- ✅ **能完成**：检查是否完成了基本内容
- ✅ **能优化**：给出简单明确的改进建议

---

## 📋 简化后的架构

### **两个检查模式**

```
┌─────────────────────────────────────┐
│  基础检查（快速）                    │
│  - 2-3秒                            │
│  - 本地规则                          │
│  - 自动触发                          │
└─────────────────────────────────────┘

│  - 手动触发                          │
└─────────────────────────────────────┘
```

## 📊 基础检查（4个核心指标）

### **1. 世界观检查**
```javascript
检查项：
✓ 是否填写了 故事背景
✓ 是否填写了 核心主题

结果：
- 全部填写 → ✅ 已完成
- 部分填写 → ⚠️ 建议补充
- 都没填写 → ❌ 请先填写
```

### **2. 角色检查**
```javascript
检查项：
✓ 是否有至少1个主角（男主/女主）
✓ 是否有至少1个配角

结果：
- 有主角+配角 → ✅ 已完成
- 只有主角 → ⚠️ 建议增加配角
- 没有主角 → ❌ 必须创建主角
```

### **3. 大纲检查**
```javascript
检查项：
✓ 是否有剧情节点（至少5个）

结果：
- 有≥10个节点 → ✅ 已完成
- 有5-9个节点 → ⚠️ 可以继续补充
- 有<5个节点 → ❌ 节点过少
```

### **4. 分集检查**
```javascript
检查项：
✓ 已完成集数 / 目标集数

结果：
- 100%完成 → ✅ 已全部完成
- 50%-99% → ⏳ 进行中 (X/Y集)
- <50% → 📝 刚开始 (X/Y集)
```

## 🚨 问题检测（只保留阻断性问题）

### **必须修复的问题**
```
❌ 没有主角
❌ 角色名重复
❌ 大纲完全为空
```

### **建议优化的问题**
```
⚠️ 世界观描述过短
⚠️ 角色缺少性格描述
⚠️ 某一幕没有节点
⚠️ 分集内容过短/过长
⚠️ 角色未在大纲出现
```

---

## 💡 优化建议（简化为3种）

### **1. 立即修复**
```
优先级：Critical
示例：
- "缺少主角，请创建男主或女主" [去创建]
- "第二幕没有节点，请添加" [去添加]
```

### **2. 建议优化**
```
优先级：Medium
示例：
- "世界观描述较短，建议补充到100字以上"
- "角色'李华'缺少背景故事"
```

### **3. 可选增强**
```
优先级：Low
示例：
- "可以增加2-3个配角丰富剧情"
- "建议在大纲中增加情感节点"
```

{{outline}}

{{episodes}}

2. 复制到 ChatGPT/Claude/文心一言
3. 查看AI的回答
4. 根据建议优化剧本

## 📈 评分体系（极简版）

### **就绪度评分（0-100分）**

```javascript
计算公式：
就绪度 = (世界观完整度 × 25%) 
       + (角色完整度 × 25%)
       + (大纲完整度 × 25%)
       + (分集完整度 × 25%)

评级：
90-100分 → 优秀 ⭐⭐⭐⭐⭐
70-89分  → 良好 ⭐⭐⭐⭐
50-69分  → 及格 ⭐⭐⭐
<50分    → 需完善 ⭐⭐
```

**各项完整度计算**：
```javascript
// 世界观完整度
必填字段数量 / 总字段数量 × 100%

// 角色完整度
(有主角?50:0) + (有配角?50:0)

// 大纲完整度
实际节点数 / 期望节点数(10个) × 100%

// 分集完整度
已完成集数 / 目标集数 × 100%
```

## ✅ 简化后的优势

1. **理解成本低**：用户一眼就能看懂
2. **决策简单**：只有"修复"和"优化"两种选择
3. **不打断流程**：不会因为复杂规则限制创作自由
4. **快速反馈**：2-3秒出结果
5. **可扩展**：未来可以逐步增加高级功能

## 🎯 核心原则

> "好的工具应该是**助手**，而不是**审判官**"

- ✅ 给建议，不强制
- ✅ 帮助创作，不限制创作
- ✅ 突出重点，不过度细分
- ✅ 快速简单，不复杂繁琐
