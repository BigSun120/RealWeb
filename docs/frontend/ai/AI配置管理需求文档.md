## 📝 需求概述

### 核心需求

为平台提供 **统一的 AI 配置管理系统**，支持用户：
- 配置和管理 AI 服务
- 选择使用模式（手动/自带密钥/平台代付）
- 管理多个 AI 平台的密钥
- 查看使用统计和费用

### 设计原则

1. **统一性**
   - 所有工具共享同一套 AI 配置
   - 用户只需配置一次，全平台可用

2. **灵活性**
   - 支持多种使用模式
   - 支持多个 AI 平台
   - 支持工具级别的个性化配置

3. **安全性**
   - 密钥加密存储
   - 权限控制
   - 异常检测

4. **可扩展性**
   - 易于接入新的 AI 平台
   - 易于支持新的工具
   - 配置数据结构可扩展

## 💼 商业模式

### 三层模式设计

采用 **三层模式**，满足不同用户需求：

#### 1. 手动模式（免费）

**特点：**
- 不使用任何 AI 功能
- 用户完全手动操作
- 永久免费，无限制

**适用场景：**
- 用户有足够的专业能力
- 不想依赖 AI
- 预算为零

**配置要求：**
- 无需配置
- 默认模式

---

#### 2. 自带密钥模式（推荐）⭐

**特点：**
- 用户使用自己的 API 密钥
- 支持多个 AI 平台
- 费用由用户直接向 AI 服务商支付
- 平台零成本

**适用场景：**
- 已有 AI 平台账号的用户
- 需要高质量 AI 模型的专业用户
- 使用频率较高的用户

**配置要求：**
- 用户需要在 AI 平台注册账号
- 获取 API Key
- 在平台配置页面填入密钥

**平台责任：**
- 提供配置界面
- 密钥安全存储
- 提供配置教程
- 费用估算（帮助用户了解成本）

---

#### 3. 平台代付模式（增值服务）

**特点：**
- 平台提供 API 密钥池
- 用户消耗平台提供的 API 配额
- 免费额度 + 付费购买

**适用场景：**
- 新手用户，不想注册 AI 平台
- 偶尔使用的用户
- 想快速体验的用户

**配置要求：**
- 无需额外配置
- 选择平台代付模式即可

**额度规则：**
- 免费额度：每日 10 次
- 付费额度包：
  - 100 次 / ¥19
  - 300 次 / ¥49
  - 1000 次 / ¥129
- 订阅制（可选）：
  - 基础版：¥29/月
  - 专业版：¥69/月

**平台责任：**
- 提供稳定的 API 服务
- 防滥用机制
- 额度管理和购买流程
- 成本监控

## ⚙️ 功能需求

### 1. 模式选择

#### 1.1 配置入口

**位置：**
- 全局入口：用户设置 → AI 配置
- 工具入口：每个 AI 工具内可快速访问配置

**展示要求：**
- 清晰的模式对比卡片
- 每种模式的特点说明
- 推荐标识（推荐自带密钥模式）
- 当前使用模式的高亮显示

#### 1.2 模式切换

**功能描述：**
用户可以随时切换模式。

**切换逻辑：**
- 从手动模式切换到其他模式：需要完成相应配置
- 从自带密钥切换到平台代付：保留密钥配置，仅切换使用方式
- 从平台代付切换到自带密钥：需要配置密钥

**提示要求：**
- 切换前确认（如有未保存配置）
- 切换后生效提示

### 2. AI 平台配置（自带密钥模式）

#### 2.1 支持的 AI 平台

**必须支持（第一阶段）：**

1. **OpenAI**
   - API 地址：`https://api.openai.com/v1`
   - 支持模型：
     - gpt-3.5-turbo（性价比高）
     - gpt-4o-mini（平衡）
     - gpt-4o（质量高）

2. **DeepSeek** ⭐ 推荐
   - API 地址：`https://api.deepseek.com/v1`
   - 支持模型：
     - deepseek-chat（性价比最高）
   - 优势：中文友好，价格低

3. **智谱 AI（GLM）**
   - API 地址：`https://open.bigmodel.cn/api/paas/v4`
   - 支持模型：
     - glm-4（国内平台）
   - 优势：国内服务，稳定

**可选支持（第二阶段）：**

4. **Anthropic Claude**
   - API 地址：`https://api.anthropic.com/v1`
   - 支持模型：
     - claude-3-haiku（快速）
     - claude-3-5-sonnet（高质量）

5. **阿里通义千问**
   - API 地址：待定
   - 支持模型：
     - qwen-turbo
     - qwen-plus

#### 2.2 配置项

**必填项：**
- AI 平台选择（下拉列表）
- API 密钥（密码输入框，支持显示/隐藏）
- 模型选择（根据平台动态显示）

**可选项：**
- Base URL（支持中转 API）
- 温度参数（0.1-2.0，默认 0.8）
- 最大 Token 数（默认 2000）
- 超时时间（默认 30 秒）
- 请求频率限制（可选）

#### 2.3 密钥管理

**功能要求：**
- 支持保存多套配置（如工作账号、个人账号）
- 支持切换配置
- 支持导入/导出配置（加密）
- 支持删除配置

**密钥显示：**
- 默认掩码显示：`sk-1234...abcd`
- 点击"显示"按钮可查看完整密钥
- 复制按钮

**测试功能：**
- "测试连接"按钮
- 验证密钥是否有效
- 测试 API 是否可用
- 显示响应时间

### 3. 密钥安全

#### 3.1 存储方式

**自带密钥模式：**
- 加密后存储在浏览器 localStorage
- 使用 AES-256 加密
- 不上传到服务器（除非用户选择云同步）

**平台代付模式：**
- 平台密钥存储在服务器
- 加密存储，权限控制
- 定期轮换

#### 3.2 传输安全

- HTTPS 加密传输
- 前端调用可选：
  - 直接调用 AI API（适合信任的用户）
  - 通过后端代理（增加一层保护，推荐）

#### 3.3 异常检测

**监控项：**
- 异常高频调用（可能被盗用）
- 连续失败（密钥可能失效）
- 费用突增（异常使用）

**处理方式：**
- 实时提醒用户
- 建议更换密钥
- 临时冻结（严重情况）

---

### 4. 使用统计

#### 4.1 统计维度

**全局统计：**
- 总调用次数
- 今日调用次数
- 本月调用次数
- 各工具使用分布（短剧生成 60%、写作助手 30% 等）

**工具级统计：**
- 每个工具的调用次数
- 每个功能的调用次数（如短剧中的角色生成、大纲生成）

**模型级统计：**
- 各模型的使用次数
- 各模型的平均响应时间

#### 4.2 展示方式

**数据卡片：**
- 今日使用：X 次
- 本月使用：X 次
- 总使用：X 次

**图表：**
- 使用趋势（折线图）
- 工具分布（饼图）
- 模型对比（柱状图）

**导出功能：**
- 导出 CSV 报表
- 导出 PDF 报告

### 5. 费用管理

#### 5.1 费用估算（自带密钥模式）

**功能描述：**
帮助用户估算 AI 调用费用。

**计算方式：**
- 记录每次调用的 Token 消耗
- 根据模型价格计算费用
- 累加统计

**展示内容：**
- 单次调用费用：¥0.05
- 今日预估费用：¥2.35
- 本月预估费用：¥45.60
- 不同模型的费用对比

**预警功能：**
- 设置月度预算
- 超过预算提醒
- 高费用操作二次确认

#### 5.2 额度管理（平台代付模式）

**功能描述：**
管理平台提供的免费额度和付费额度。

**额度展示：**
- 免费额度：今日剩余 8/10 次
- 付费额度：剩余 245 次
- 额度用尽时间预估

**购买入口：**
- 额度不足提醒
- 快速购买入口
- 额度包选择
- 支付流程

**额度历史：**
- 购买记录
- 消耗记录
- 充值记录

### 6. 工具级配置（可选）

#### 6.1 功能描述

允许用户为不同工具设置不同的 AI 配置。

**场景举例：**
- 短剧生成：使用 GPT-4（质量优先）
- 写作助手：使用 DeepSeek（性价比优先）
- 翻译工具：使用智谱 GLM（国内场景）

#### 6.2 配置继承

**规则：**
- 默认使用全局配置
- 工具可以覆盖全局配置
- 未覆盖的项继承全局配置

**配置优先级：**
```
工具级配置 > 全局配置 > 系统默认配置
```

## 🎨 用户体验要求

### 1. 配置流程

**首次配置（新用户）：**
1. 进入 AI 配置页面
2. 选择模式（引导推荐自带密钥）
3. 选择 AI 平台
4. 填入 API Key
5. 测试连接
6. 保存配置
7. 开始使用

**时间要求：** ≤ 3 分钟

### 2. 配置引导

**新手引导：**
- 欢迎弹窗，介绍三种模式
- 推荐自带密钥模式
- 提供各平台的注册链接和教程
- 图文并茂的配置步骤

**帮助文档：**
- 常见问题 FAQ
- 视频教程
- 在线客服

### 3. 错误处理

**常见错误：**
- 密钥无效：提示检查密钥格式，提供重新配置入口
- 余额不足：提示充值（AI 平台账户）
- 网络超时：提示检查网络，提供重试
- 模型不可用：提示选择其他模型

**用户友好提示：**
- 错误信息清晰易懂
- 提供解决方案
- 提供帮助链接

## 💰 成本控制

### 1. 平台代付模式成本

**预算估算：**
- 假设 1000 活跃用户
- 每人每日 10 次免费（使用率 50%）
- 5000 次/日 × ¥0.05/次 = ¥250/日
- 月成本：¥7,500

**控制措施：**
- 限制免费额度
- 防滥用机制（频率限制、验证码）
- 引导用户转向自带密钥
- 付费转化（目标转化率 10%）

### 2. 成本监控

- 实时成本统计
- 异常用户检测
- 成本预警（超过预算提醒）
- 定期优化（选择更便宜的模型）

## 🔧 扩展性设计

### 1. 接入新 AI 平台

**要求：**
- 只需添加新的适配器（Provider）
- 无需修改核心配置逻辑
- 配置界面自动适配

**示例：**
```
添加新平台：Kimi AI
1. 创建 KimiProvider.js
2. 注册到 aiService
3. 添加平台配置元数据
4. 完成！
```

### 2. 支持新工具

**要求：**
- 新工具自动继承全局配置
- 可选：工具级个性化配置
- 统计和费用自动跟踪

**示例：**
```
新工具：AI 写作助手
1. 调用 aiService.generate()
2. 自动使用用户的全局配置
3. 自动记录统计数据
4. 完成！
```

### 3. 配置数据结构

**设计要求：**
- 可扩展的 JSON 结构
- 向后兼容（旧版本配置可用）
- 版本控制
