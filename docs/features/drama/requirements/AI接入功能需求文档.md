## 🎯 项目背景

### 现状分析

**当前版本特点：**
- ✅ 用户完全手动填写所有内容
- ✅ 提供模板和提示词引导
- ✅ 完全免费，无成本压力
- ❌ 创作效率低，需要用户有较强的创作能力
- ❌ 对新手用户不够友好
- ❌ 无法快速生成完整剧本

**市场需求：**
- 用户希望 AI 能够辅助创作，提高效率
- 专业编剧需要快速生成初稿
- 新手用户需要 AI 引导和灵感
- 用户对 AI 生成内容质量有较高期望

### 目标用户

1. **专业编剧**
   - 需要快速生成多个剧本方案对比
   - 对 AI 生成质量要求高
   - 愿意为优质模型付费

2. **业余创作者**
   - 希望 AI 提供灵感和框架
   - 预算有限，倾向于免费或低成本方案
   - 需要简单易用的界面

3. **内容生产公司**
   - 批量生产剧本需求
   - 需要团队协作功能
   - 愿意为企业级服务付费

## 📝 需求概述

### 核心需求

为 AI 短剧剧本生成器增加 **AI 自动生成功能**，支持用户使用 AI 辅助创作，包括：
- 角色自动生成
- 大纲自动生成
- 分集剧本自动生成
- 内容优化和续写

### 商业模式

采用 **三层模式**，满足不同用户需求：

1. **手动模式（免费）**
   - 保持现有功能不变
   - 完全手动创作

2. **自带密钥模式（推荐）** ⭐
   - 用户使用自己的 API 密钥
   - 支持多个 AI 平台
   - 平台零成本

3. **平台代付模式（增值服务）**
   - 提供免费体验额度
   - 超出额度后付费购买
   - 提供订阅套餐

## 👥 用户场景

### 场景 1：新手用户快速创建剧本

**用户故事：**
> 小明是一个短剧爱好者，想创作自己的剧本，但没有专业编剧经验。他希望通过 AI 快速生成一个完整的剧本框架，然后根据自己的想法进行修改。

**操作流程：**
1. 小明创建新项目，输入基本设定（玄幻风格、30 集）
2. 点击"AI 生成世界观"，系统自动生成详细的世界观设定
3. 点击"AI 生成角色"，系统生成主角、配角等多个角色
4. 点击"AI 生成大纲"，系统生成 30 集的完整故事大纲
5. 逐集点击"AI 生成剧本"，系统生成每集的详细剧本
6. 小明对部分内容不满意，手动修改或重新生成
7. 导出完整剧本

**期望结果：**
- 1 小时内完成 30 集剧本初稿
- AI 生成内容质量达到可用标准（80% 以上满意度）
- 用户可以轻松修改和调整

### 场景 2：专业编剧使用自己的 API 密钥

**用户故事：**
> 张编剧是一名专业编剧，已经有 OpenAI 的 API 账户。他希望使用自己的密钥来调用 GPT-4 生成高质量剧本，并且希望能够自定义提示词。

**操作流程：**
1. 张编剧进入"用户设置" → "AI 配置"
2. 选择"自带密钥模式"
3. 选择 AI 平台：OpenAI
4. 填入自己的 API Key
5. 选择模型：GPT-4o
6. （可选）自定义提示词模板
7. 保存配置
8. 在创作时，系统使用他的密钥调用 GPT-4
9. 张编剧可以查看 API 调用次数和费用统计

**期望结果：**
- 配置过程不超过 2 分钟
- 支持主流 AI 平台（OpenAI、Claude、DeepSeek 等）
- 密钥安全存储，不泄露
- 生成速度快，质量高

### 场景 3：用户使用平台提供的免费额度

**用户故事：**
> 李同学想尝试 AI 生成功能，但不想注册 AI 平台账号，也不想付费。他希望先用平台提供的免费额度体验一下效果。

**操作流程：**
1. 李同学在"AI 配置"中选择"平台代付模式"
2. 系统显示：今日剩余免费次数 10/10
3. 李同学使用 AI 生成角色（消耗 1 次）
4. 生成大纲（消耗 1 次）
5. 生成 3 集剧本（消耗 3 次）
6. 系统提示：今日剩余 5 次
7. 次日额度重置，或李同学选择购买额度包

**期望结果：**
- 免费额度足够体验核心功能
- 付费引导清晰，不强制
- 价格合理（如 ¥19/100 次）

## ⚙️ 功能需求

### 1. AI 配置管理

#### 1.1 模式选择

**功能描述：**
用户可以在三种模式中选择：

- **手动模式**
  - 不使用 AI
  - 完全手动创作
  - 永久免费

- **自带密钥模式** ⭐ 推荐
  - 使用用户自己的 API 密钥
  - 支持多个 AI 平台
  - 用户自行承担费用

- **平台代付模式**
  - 使用平台提供的 API
  - 免费额度 + 付费购买
  - 开箱即用

**交互要点：**
- 清晰的模式对比表格
- 每种模式的优缺点说明
- 推荐标识（推荐自带密钥模式）

#### 1.2 AI 平台配置

**功能描述：**
支持用户配置多个主流 AI 平台：

**必须支持：**
1. **OpenAI**
   - GPT-3.5 Turbo（性价比高）
   - GPT-4o mini（平衡）
   - GPT-4o（质量高）

2. **DeepSeek** ⭐ 推荐
   - DeepSeek V3（性价比最高）
   - 适合中文创作

3. **智谱 AI（GLM）**
   - GLM-4（国内平台）
   - 支持中文场景

**可选支持：**
4. **Claude**
   - Claude 3 Haiku（快速）
   - Claude 3.5 Sonnet（高质量）

5. **通义千问**
   - 国内平台
   - 阿里云服务

**配置项：**
- AI 平台选择（下拉列表）
- API 密钥输入（密码输入框，可显示/隐藏）
- 模型选择（根据平台动态显示）
- Base URL（可选，支持中转 API）
- 温度参数（0.1-2.0，默认 0.8）
- 最大 Token 数（默认 2000）

**交互要点：**
- 提供各平台的注册链接和教程
- 测试连接功能（验证密钥是否有效）
- 保存后显示配置成功提示
- 支持多套配置切换（如工作用 OpenAI，个人用 DeepSeek）

#### 1.3 密钥安全存储

**功能描述：**
确保用户的 API 密钥安全存储，不会泄露。

**安全措施：**
1. **本地加密存储**
   - 密钥加密后存储在浏览器 localStorage
   - 使用 AES 加密算法
   - 密钥不上传到服务器（自带密钥模式）

2. **前端直接调用**
   - 可选：前端直接调用 AI API（适合信任的用户）
   - 可选：通过后端代理（增加一层保护）

3. **密钥掩码显示**
   - 显示时只显示前 4 位和后 4 位
   - 如：`sk-1234...abcd`

4. **定期提醒**
   - 提醒用户定期更换密钥
   - 密钥异常时（如被盗用）及时提醒

### 2. AI 生成功能

#### 2.1 世界观自动生成

**功能描述：**
根据用户输入的简单设定，AI 自动生成完整的世界观。

**输入要求：**
- 风格类型（玄幻、都市、古装、科幻等）
- 剧集数量（10 集、20 集、30 集等）
- 关键词（可选，如"复仇"、"爱情"、"权谋"）
- 参考作品（可选，如"参考《甄嬛传》风格"）

**输出内容：**
- 时代背景
- 地点设定
- 世界规则
- 核心冲突
- 时代特色

**交互要点：**
- 支持重新生成（如果不满意）
- 支持部分修改后续写
- 显示生成进度和预估时间

#### 2.2 角色自动生成

**功能描述：**
基于世界观，AI 自动生成角色。

**输入要求：**
- 当前世界观
- 角色类型（主角、配角、反派）
- 角色数量
- 特殊要求（可选，如"女性，25 岁，霸道总裁"）

**输出内容：**
- 角色名称
- 年龄、性别
- 性格特点
- 背景故事
- 人物关系
- 角色目标

**交互要点：**
- 支持批量生成（如一次生成 5 个角色）
- 支持逐个生成（精细控制）
- 自动分析角色关系，生成关系图

#### 2.3 大纲自动生成

**功能描述：**
基于世界观和角色，AI 自动生成完整的剧情大纲。

**输入要求：**
- 世界观
- 角色列表
- 剧集数量
- 剧情风格（紧凑、舒缓、悬疑等）
- 关键情节点（可选，用户指定必须包含的情节）

**输出内容：**
- 整体故事走向
- 主要情节线
- 每集简要梳概
- 关键冲突点
- 结局方向

**交互要点：**
- 支持整体生成或分阶段生成（前 10 集、中 10 集、后 10 集）
- 支持调整后重新生成后续部分
- 显示大纲的完整性评分

#### 2.4 分集剧本自动生成

**功能描述：**
基于大纲，AI 自动生成每集的详细剧本。

**输入要求：**
- 世界观
- 角色列表
- 大纲（整体和当前集）
- 目标字数（如 3000 字、5000 字）
- 特殊要求（可选，如"增加动作戏份"）

**输出内容：**
- 场景描述
- 人物对话
- 动作描写
- 情感描写
- 冲突点

**交互要点：**
- 支持逐集生成（点击某一集生成）
- 支持批量生成（如一次生成 5 集）
- 显示生成进度条
- 支持暂停和继续
- 支持续写和扩写

#### 2.5 内容优化和改写

**功能描述：**
对已有内容进行 AI 优化、续写、扩写、改写。

**功能类型：**

1. **优化**
   - 改善语言表达
   - 增强情感渲染
   - 优化对话自然度

2. **续写**
   - 基于现有内容继续创作
   - 保持风格一致

3. **扩写**
   - 将简短内容扩展为详细描述
   - 增加细节和场景

4. **改写**
   - 改变叙述视角
   - 调整剧情走向
   - 改变风格（如从严肃改为轻松）

**交互要点：**
- 选中文本后右键菜单操作
- 或工具栏快捷按钮
- 显示修改前后对比
- 支持接受或拒绝修改
