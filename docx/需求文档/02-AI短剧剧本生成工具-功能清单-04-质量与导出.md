# 功能清单-04-质量与导出

> **模块说明**: 本模块负责内容质量检查、一键复制和多格式导出功能

---

## 1. 质量检查与一致性维护

### 1.1 人物一致性检查

#### 1.1.1 称谓一致性 【P1】
**检查内容**:
- 同一角色的多种称呼（"李雨晴"/"小李"/"雨晴"）
- 提示可能的混用情况

**示例**:
```
⚠️ 称谓不一致警告

角色：李雨晴
- 第1-5集: 称呼为"李雨晴" (主要)
- 第8集: 出现"小李" (1次)
- 第12集: 出现"雨晴" (3次)

建议：统一使用"李雨晴"，或明确不同称呼的使用场景
```

#### 1.1.2 性格OOC检测 【P2】
**检查方式**:
- 基于角色卡的性格标签
- 标记与人设不符的行为描述
- 提供"可能OOC"的提示

**示例**:
```
⚠️ 可能的性格偏离

角色：李雨晴（设定：独立、倔强）
第15集，场景3：
"李雨晴低声下气地请求陈墨原谅"

此描述可能与角色"倔强"的性格设定不符，请确认。
```

### 1.2 时间线一致性

#### 1.2.1 时间跨度检查 【P1】
**检查项**:
- 季节变化（第1集夏天，第5集突然下雪）
- 时间跳跃（昨天刚发生，今天说是上周）
- 角色年龄变化

**输出**:
```
📅 时间线分析

第1-10集：夏季（6-8月）
第11集：出现"雪花飞舞" ⚠️ 可能的季节跳跃
第12-20集：冬季（12月）

建议：在第10-11集间增加时间过渡说明
```

#### 1.2.2 事件顺序逻辑 【P1】
- 检查前后事件的因果关系
- 标记逻辑矛盾（A事件后发生B，但B依赖的前提未满足）

### 1.3 情节逻辑检查

#### 1.3.1 伏笔追踪 【P1】
**功能**:
- 用户手动标记伏笔
- 系统追踪伏笔是否已回收
- 提醒未解决的悬念

**数据结构**:
```json
{
  "id": "foreshadow_001",
  "content": "女主项链的秘密",
  "introducedAt": 3,  // 第3集埋下
  "resolvedAt": null,  // 未解决
  "importance": "高",
  "status": "pending"
}
```

**显示**:
```
🎯 伏笔追踪

✅ 已回收:
- 男主的家族秘密 (第5集埋下 → 第15集揭晓)

⏳ 待回收:
- 女主项链的秘密 (第3集埋下，已过12集)
- 神秘信件的寄件人 (第8集出现)
```

#### 1.3.2 悬念提醒 【P1】
- 检测以问句或悬念结尾的情节
- 提醒在后续剧集中解答

### 1.4 格式规范检查

#### 1.4.1 场景格式 【P0】
**标准格式**: 【场景X：时间/内外/地点】

**检查**:
- 缺少场景标识
- 格式不规范（缺少时间或地点）
- 场景编号不连续

#### 1.4.2 对白标点 【P1】
- 中文对白用中文标点
- 对白结尾统一（句号/感叹号/问号）
- 提示标点错误（，。混用）

#### 1.4.3 人名统一 【P0】
- 全文人名拼写统一
- 检测可能的笔误（"李雨晴"写成"李宇晴"）

## 2. 一键复制功能

### 2.1 提示词复制 【P0】
**功能**:
- 一键复制生成的提示词
- 自动去除多余空行
- 可选添加边界标识

**边界标识**:
```
========== AI提示词 ==========
[内容]
========== 结束 ==========

提示：请将以上内容复制到AI平台（ChatGPT/Claude等）
```

### 2.2 内容复制选项 【P1】
**复制格式**:
- 纯文本（去除所有格式）
- Markdown（保留格式）
- HTML（用于邮件/网页）

**批量复制**:
- 复制选中的多集剧本
- 自动添加分隔符

## 3. 多格式导出

### 3.1 Markdown导出 【P0】

#### 3.1.1 完整剧本导出
**包含内容**:
```markdown
# 《项目名称》剧本

## 项目信息
- 类型：霸道总裁
- 集数：30集
- 创作日期：2025-10-12

## 角色表
### 主要角色
1. **李雨晴**（女主）
   - 年龄：25岁
   - 职业：设计师
   - 性格：独立、善良、倔强

...

## 剧情大纲
### 第一幕（1-10集）
...

## 分集剧本
### 第1集
#### 场景1：日/外/公司门口
...
```

#### 3.1.2 导出选项
- **完整导出**: 包含所有内容
- **仅剧本**: 只导出剧本部分
- **分集导出**: 选择特定集数导出
- **大纲+剧本**: 不包含角色表

### 3.2 Word导出 【P1】

#### 3.2.1 样式配置
**可配置项**:
- 字体：宋体/黑体/自定义
- 字号：标题（14-18pt）正文（10-12pt）
- 行距：单倍/1.5倍/2倍
- 页边距：窄/普通/宽

#### 3.2.2 文档结构
- 自动生成目录
- 页码
- 页眉页脚（项目名称/日期）
- 分节符（每集/每幕）

#### 3.2.3 格式优化
- 角色对白加粗
- 场景标题突出
- 动作描述斜体
- 关键情节高亮（可选）

### 3.3 PDF导出 【P1】

#### 3.3.1 基础功能
- 基于Word样式生成PDF
- 或直接从Markdown转PDF
- 保留所有格式和样式

#### 3.3.2 PDF特性
- 添加书签（目录导航）
- 添加水印（可选："草稿"/"终稿"）
- 页码和章节标记
- 文档属性（作者、标题、创建日期）

#### 3.3.3 打印优化
- A4/Letter纸张大小
- 适合双面打印
- 章节从奇数页开始（可选）

### 3.4 JSON导出 【P1】

#### 3.4.1 完整项目数据导出
**用途**: 备份、迁移、分享完整项目

**数据结构**:
```json
{
  "version": "1.0",
  "exportDate": "2025-10-12",
  "project": {
    "id": "proj_001",
    "name": "霸道总裁追妻记",
    "settings": {...},
    "characters": [...],
    "outline": {...},
    "episodes": [...]
  }
}
```

#### 3.4.2 JSON导入
- 验证JSON格式
- 检查版本兼容性
- 导入前预览
- 选择性导入（只导入角色/只导入大纲）

### 3.5 导出模板系统 【P2】

#### 3.5.1 自定义导出模板
**功能**:
- 创建自定义导出格式
- 选择包含/排除的内容
- 自定义样式和布局
- 保存为可复用模板

**示例模板**:
- 完整版（项目信息+角色+大纲+剧本）
- 简版（仅剧本）
- 提案版（项目信息+大纲+前3集）
- 审核版（大纲+完整剧本）

## 4. 导出管理

### 4.1 导出历史 【P1】
**记录内容**:
- 导出时间
- 导出格式（MD/Word/PDF）
- 导出范围（完整/部分）
- 文件大小

**功能**:
- 查看历史导出记录
- 重新导出（使用相同配置）
- 下载历史导出文件（如果保留）

### 4.2 导出预览 【P1】
**功能**:
- 导出前预览最终效果
- 检查格式是否正确
- 调整后再导出

### 4.3 批量导出 【P2】
- 一次导出多种格式
- 导出为压缩包
- 按集数/章节拆分多个文件
