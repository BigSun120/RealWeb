# 项目状态自动管理说明

## 修复时间
2025-10-13 14:15

## 问题背景

用户反馈：**正在制作分集了，但是项目状态还是显示"设定中"**

原因：项目状态被硬编码为 `'设定中'`，没有根据实际进度自动更新。

---

## 状态定义

### 📋 四种状态

| 状态 | 图标颜色 | 说明 | 典型阶段 |
|------|---------|------|----------|
| **设定中** | 🔵 Info（蓝色） | 正在设定世界观和角色 | 初期创作 |
| **大纲中** | 🟡 Warning（橙色） | 已有大纲，准备或开始分集 | 规划阶段 |
| **剧本中** | 🟣 Primary（紫色） | 正在创作分集剧本 | 主要创作期 |
| **已完成** | 🟢 Success（绿色） | 所有分集已完成 | 完成状态 |

---

## 自动判断规则

### 🎯 状态判断逻辑（按优先级）

#### 1. **已完成** ✅
**条件**（同时满足）：
- 当前分集数 ≥ 目标集数
- 已完成分集数 ≥ 目标集数

**示例**：
- 目标：60集
- 当前：60集
- 完成：60集
- → **已完成**

---

#### 2. **剧本中** 📝
**条件**（同时满足）：
- 有分集（> 0）
- 有已完成的分集（> 0）

**示例**：
- 当前：10集
- 完成：5集
- → **剧本中**

**说明**：只要有任何一集完成，就认为进入剧本创作阶段

---

#### 3. **大纲中** 📖
**条件**（满足任一）：

**3.1 有大纲 + 有分集（但无完成）**
- 大纲有节点
- 有分集但都未完成
- → **大纲中**

**示例**：
- 大纲：已添加10个节点
- 分集：创建了5集，但都是草稿
- → **大纲中**

**3.2 只有大纲（无分集）**
- 大纲有节点
- 没有分集
- → **大纲中**

**示例**：
- 大纲：已添加节点
- 分集：0集
- → **大纲中**

---

#### 4. **设定中** 🔧
**条件**：不满足以上任何条件

**示例**：
- 只有世界观或角色
- 没有大纲节点
- → **设定中**

## 代码实现

### 核心函数

#### 1. `calculateProjectStatus()`
```javascript
const calculateProjectStatus = () => {
  const targetEpisodes = project.episodeCount || 60;
  const currentEpisodes = episodes.value.length;
  const completedEpisodes = episodes.value.filter(
    ep => ep.status === 'completed' || ep.status === 'reviewed'
  ).length;
  
  // 1. 已完成
  if (currentEpisodes >= targetEpisodes && completedEpisodes >= targetEpisodes) {
    return '已完成';
  }
  
  // 2. 剧本中：有分集且有完成的
  if (currentEpisodes > 0 && completedEpisodes > 0) {
    return '剧本中';
  }
  
  // 3. 大纲中：有大纲节点
  const hasOutlinePoints = outline.value?.acts?.some(
    act => act.plotPoints && act.plotPoints.length > 0
  ) || false;
  
  if (hasOutlinePoints && currentEpisodes > 0) {
    return '大纲中'; // 有大纲且有分集（但未完成）
  }
  
  if (hasOutlinePoints) {
    return '大纲中'; // 只有大纲
  }
  
  // 4. 默认：设定中
  return '设定中';
};
```

#### 2. `updateProjectStatus()`
```javascript
const updateProjectStatus = async () => {
  const newStatus = calculateProjectStatus();
  if (newStatus !== project.status) {
    const oldStatus = project.status;
    project.status = newStatus;
    
    // 更新到服务器
    await updateDramaProject(project._id || project.id, {
      status: newStatus
    });
    
    console.log(`项目状态更新: ${oldStatus} -> ${newStatus}`);
  }
};
```

## 触发时机

状态会在以下操作后自动更新：

### ✅ 保存世界观
- 调用时机：`handleSaveWorldview()` 完成后
- 触发：`updateProjectStatus()`

### ✅ 保存角色
- 调用时机：`handleSaveCharacters()` 完成后
- 触发：`updateProjectStatus()`

### ✅ 保存大纲
- 调用时机：`handleSaveOutline()` 完成后
- 触发：`updateProjectStatus()`
- **重要**：添加大纲节点后保存会触发状态从"设定中"→"大纲中"

### ✅ 保存分集
- 调用时机：`handleSaveEpisodes()` 完成后
- 触发：`updateProjectStatus()`
- **重要**：
  - 创建分集：可能触发"大纲中"
  - 完成分集：触发"剧本中"
  - 完成所有：触发"已完成"

## 状态流转示例

### 🔄 完整流程

```
新建项目
    ↓
[设定中] - 填写世界观、创建角色
    ↓ 添加大纲节点 → 保存
[大纲中] - 创建分集（未完成）
    ↓ 完成第1集 → 保存
[剧本中] - 继续创作分集
    ↓ 完成最后一集（第60集）→ 保存
[已完成] - 所有分集完成
```

```
步骤4：添加大纲节点

步骤5：创建10个分集（都是草稿）
  操作：保存分集
  状态：大纲中（不变）

步骤6：完成第1集

```

```

- 世界观：✓

  ↓
自动检测：有大纲节点 + 有分集
  ↓

```

## 状态与进度的关系

### 区别

| 维度 | 状态 (status) | 进度 (progress) |
|------|--------------|-----------------|
| 类型 | 文本标签 | 百分比数字 |
| 含义 | 创作阶段 | 完成比例 |
| 更新 | 阶段性跳转 | 连续增长 |
| 示例 | "剧本中" | 45% |

### 关系

```
状态：设定中
进度：0%
说明：还在准备阶段

状态：大纲中
进度：0-10%
说明：有大纲但分集少

状态：剧本中
进度：10-99%
说明：正在创作，完成度不断提升

状态：已完成
进度：100%
说明：所有分集完成
```
