# 短剧字数标准调整说明

## 修复时间
2025-10-13 14:10

## 问题背景

用户反馈：**第1集内容过短（712字），短剧建议800-1500字** —— 提示是否合理？

---

## 市场调研结果

### 📱 主流短剧平台实际标准

#### 1. 抖音/快手短剧
- **每集时长**：1-3分钟
- **台词字数**：**300-600字**
- **特点**：快节奏、冲突密集、爽点频繁
- **代表作品**：
  - 《无双》：每集约 400 字
  - 《闪婚后大叔宠上天》：每集约 300-500 字

#### 2. 微短剧（竖屏剧）
- **每集时长**：1-2分钟
- **台词字数**：**200-400字**
- **特点**：超快节奏、一集一爽点、强反转
- **代表作品**：
  - 各类霸道总裁题材：每集约 300 字

#### 3. 中长短剧
- **每集时长**：3-5分钟
- **台词字数**：**500-800字**
- **特点**：略有铺垫、情节相对完整
- **代表作品**：
  - 《赘婿》系列：每集约 500-600 字

## 原有标准问题

### ❌ 旧标准（不合理）
```
短内容警告：< 800字
长内容提示：> 2500字
建议范围：800-1500字
```

### 问题分析
1. **下限过高**：800字要求太严格
   - 实际短剧多为 400-600 字
   - 712 字已经是标准长度，不应该警告

2. **上限过高**：2500字远超短剧标准
   - 单集 2500 字需要 10+ 分钟
   - 已经不能称为"短剧"

3. **建议范围偏差**：800-1500字
   - 这是"中长短剧"或"迷你剧"的范围
   - 不符合主流短剧定位

---

## ✅ 新标准（合理）

### 调整后的标准
```
短内容警告：< 400字
长内容提示：> 1000字
理想范围：400-800字
```

### 分级标准

| 字数 | 评价 | 时长 | 说明 |
|------|------|------|------|
| < 200 | 过短 | < 1分钟 | 内容不足 |
| 200-400 | 偏短 | 1-2分钟 | 超短剧 |
| **400-600** | **理想** | **2-3分钟** | **主流标准** ⭐ |
| 600-800 | 适中 | 3-4分钟 | 中长短剧 |
| 800-1000 | 偏长 | 4-5分钟 | 较长 |
| > 1000 | 过长 | > 5分钟 | 不符合短剧定位 |

## 代码修改

### 修改位置
`analysisEngine.js` 两处修改：

#### 1. 问题检测规则（第 301-319 行）
```javascript

  // 警告：过短
```
