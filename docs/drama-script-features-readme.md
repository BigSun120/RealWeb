# 剧本生成工具批量功能快速参考

## 🎯 实现的三大核心功能

### 1️⃣ 批量角色生成（CharacterManager）
```
[🪄 AI批量生成] [📋 批量导入] [➕ 添加角色]
```
- 一次生成多个角色提示词
- 智能解析AI回复，批量导入角色
- 自动检查世界观完整性

### 2️⃣ 大纲AI生成（OutlineEditor）
```
[🪄 AI智能生成] [📋 导入大纲] [🪄 生成提示词] [✅ 保存]
```
- 生成完整三幕式大纲提示词
- 自动解析并填充大纲结构
- 支持导入后继续手动编辑

### 3️⃣ 集数批量创建（EpisodeManager）
```
[🪄 AI批量创建] [➕ 添加分集] [⚠️ 批量生成提示词]
```
- 快速创建多个集数框架（1-50集）
- 为所有分集生成AI提示词
- 折叠面板展示，支持单个/批量复制

## 📋 完整工作流

```
1. 世界观设定 → 保存
2. 角色管理 → [AI批量生成] → 复制提示词到ChatGPT → [批量导入] AI回复
3. 大纲编辑 → [AI智能生成] → 复制提示词到ChatGPT → [导入大纲] AI回复
4. 分集管理 → [AI批量创建] 输入集数范围 → [批量生成提示词] → 复制到ChatGPT
5. 逐个完善分集内容
```

## 🔧 技术要点

### 数据流
```
用户输入 → 生成提示词 → ChatGPT → AI回复 → 智能解析 → 填充到界面
```

### 解析标记
- **批量角色**：使用`【角色1】`、`【角色2】`等标记分隔
- **大纲**：使用`【第一幕】`、`【第二幕】`、`【第三幕】`标记分隔

### 智能检查
- 角色生成：检查世界观
- 大纲生成：检查世界观+角色
- 集数创建：检查大纲
