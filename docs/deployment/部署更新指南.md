## 3. 推荐生产部署链路（PM2 + Nginx）

### 3.1 服务器更新后端

```bash
ssh root@74.48.7.119
cd /root/RealWeb
git pull origin master
cd backend && npm install && cd ..
pm2 restart website-backend
```

### 3.2 本地构建并上传前端

```bash
cd frontend
npm install
npm run build
scp -r dist/* root@74.48.7.119:/var/www/html/
```

### 3.3 健康检查

```bash
curl -s http://localhost:8000/health
curl -s https://godaug.fun/api/health
pm2 logs website-backend --lines 40
```

## 4. 生产容器配置说明（冲突点已文档化）

当前 `docker-compose.prod.yml` 的重要字段：

- `backend` 环境变量：`PORT=8000`
- `backend` 端口映射：`3001:3001`
- `backend/Dockerfile` 暴露端口：`EXPOSE 5000`

这三者并不一致。若你要走容器化生产，请先统一为同一端口（建议统一 `8000`）。

建议目标：

- 应用监听：`8000`
- Compose 映射：`8000:8000`
- Nginx upstream：`127.0.0.1:8000` 或容器内服务名 + `8000`

## 5. 明文密码处理约定

`docker-compose.prod.yml` 已改为环境变量读取 Mongo root 密码，不再硬编码。

请在服务器 `.env`（或部署平台密钥管理）中提供：

```bash
MONGO_ROOT_USERNAME=admin
MONGO_ROOT_PASSWORD=<strong-random-password>
MONGO_DATABASE=personal_website_prod
```
