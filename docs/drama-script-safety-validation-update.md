# 剧本生成工具 - 安全性与数据校验功能更新

## 更新日期
2024年

## 新增功能概述

本次更新为剧本生成工具添加了**导入安全确认**和**数据质量校验**两项核心功能，显著提升了系统的安全性和用户体验。

## 功能详情

### 1. ✅ 大纲导入覆盖确认（OutlineEditor）

#### 功能说明
在导入AI生成的大纲前，系统会自动检测是否已有现有大纲内容，如有则弹出确认对话框，防止用户误操作覆盖重要数据。

#### 实现细节
```javascript
// 检查现有内容
const hasExistingContent = hasPlotPoints.value;

if (hasExistingContent) {
  // 弹出确认对话框
  ElMessageBox.confirm(
    `检测到已有大纲内容（共 ${totalPlotPoints.value} 个节点），
     导入将覆盖所有现有内容。是否继续？`,
    '确认覆盖',
    { type: 'warning' }
  )
}
```

#### 用户体验
- ⚠️ **警告提示**：明确告知将覆盖现有内容
- 📊 **数据展示**：显示当前节点数量
- ✅ **明确选项**："覆盖并导入" 或 "取消"
- 💡 **取消提示**：取消后显示 "已取消导入"

---

### 2. ✅ 大纲数据质量校验（OutlineEditor）

#### 功能说明
导入大纲后，系统自动校验数据完整性，统计并报告缺失字段，帮助用户识别需要完善的内容。

#### 校验项目
| 字段 | 说明 |
|------|------|
| 节点标题 | 是否为空 |
| 节点描述 | 是否为空 |
| 涉及角色 | 是否指定角色 |
| 集数范围 | 是否指定episodeRange |

#### 校验结果展示
**完整数据**：
```
✅ 成功导入大纲：3 幕，12 个节点（数据完整）
```

**不完整数据**：
```
成功导入大纲：3 幕，12 个节点

⚠️ 数据质量提示：
• 3个节点标题为空
• 5个节点描述为空
• 2个节点未指定角色
• 4个节点未指定集数

建议手动完善这些信息以获得更好的效果。
```

---

### 3. ✅ 角色数据质量校验（CharacterManager）

#### 功能说明
批量导入角色后，系统自动校验每个角色的数据完整性，提供详细的数据质量报告。

#### 校验项目
| 字段 | 说明 | 重要性 |
|------|------|--------|
| 姓名 | name | ⚠️ 关键 |
| 角色定位 | role | ⚠️ 关键 |
| 描述 | description | 重要 |
| 年龄 | age | 一般 |
| 性别 | gender | 一般 |

#### 校验结果展示
**完整数据**：
```
✅ 成功导入 5 个角色（数据完整）
```

**不完整数据**：
```
成功导入 10 个角色

✅ 完整数据：7 个
⚠️ 不完整数据：3 个

详细信息：
2个未填写姓名、1个未指定角色定位、3个缺少描述

不完整角色列表：
• 角色1：缺少 姓名、描述
• 张三：缺少 角色定位、年龄
• 李四：缺少 描述、性别

建议手动完善这些角色信息。
```

#### 显示规则
- 最多显示前5个不完整角色
- 超过5个时显示 "...还有 X 个角色信息不完整"
- 按缺失字段的严重程度排序

## 技术实现

### 文件修改

#### OutlineEditor.vue
新增函数：
- `performImport()` - 执行导入逻辑
- `validateImportedData()` - 数据质量校验
- `showImportResult()` - 显示导入结果

#### CharacterManager.vue
新增函数：
- `validateCharactersData()` - 角色数据校验
- `showCharactersImportResult()` - 显示导入结果

### 核心逻辑

#### 数据校验流程
```
解析AI回复
    ↓
数据质量校验
    ↓
统计缺失字段
    ↓
生成报告
    ↓
显示结果（完整/不完整）
```

#### 覆盖确认流程
```
用户触发导入
    ↓
检查现有内容
    ↓
有内容？
    ├─ 是 → 确认对话框
    │         ├─ 确认 → 执行导入
    │         └─ 取消 → 终止导入
    └─ 否 → 直接导入
```
