# 静态工具新增与后台显示控制指引

## 目标
- 统一由后台 `ToolsManagement` 页面控制工具在前端是否展示。
- 保留静态工具写死带来的快速接入优势，同时确保在 API 异常时仍能降级显示关键工具。

## 统一显示控制建议
1. **保持接口为唯一数据源**：前端 `ToolsIndex` 依赖 `toolsService.tools`。当 `/tools` 接口可用时，仅使用接口返回的 `status === "active"` 工具渲染列表，后台的启用/禁用即可即时生效。
2. **静态定义仅做兜底**：`frontend/src/services/toolsService.js#getStaticTools` 可以继续维护工具的默认元数据，但 `mergeStaticTools` 只在接口缺少对应 `id` 时填充（API 成功时不要覆盖数据库状态）。这样一旦后台存在同名记录，就由数据库记录主导显示。
3. **需要禁用时仅改后台状态**：通过后台页面或接口把工具状态改为 `inactive`/`coming-soon`，前端列表就会自动隐藏；静态兜底不会重复添加，因为 `mergeStaticTools` 会先检测 `Tool` 列表中是否已有相同 `id`。
4. **首次上线同步**：部署新静态工具后，使用后台创建同 `id` 的记录（或运行一次种子脚本），确保数据库里有正式记录。此后所有可见性都走后台，不需要再改前端代码。

## 新增静态工具流程
1. **准备前端页面/组件**  
   - 在 `frontend/src/views/tools` 下创建工具页面组件，例如 `frontend/src/views/tools/dev/MyTool.vue`。  
   - 组件中实现业务逻辑，并在需要鉴权时在路由 `meta.requiresAuth` 中标记。

2. **注册前端路由**  
   - 在 `frontend/src/router/tools.js` 相应分类下新增路由节点，`path` 与 `name` 建议使用短横线形式，保持与工具 `id` 一致，如 `path: 'my-tool'`、`name: 'MyTool'`。  
   - 若需要单独入口（不是分类内子项），可在 `/tools` 的 `children` 顶层追加。

3. **补充静态元数据**  
   - 在 `frontend/src/services/toolsService.js#getStaticTools` 中新增对象，字段包含：
     ```js
     {
       id: 'my-tool',
       name: '我的工具',
       description: '功能简介',
       icon: '🧰',
       category: 'dev',
       route: '/tools/dev/my-tool',
       component: '@/views/tools/dev/MyTool.vue',
       tags: ['标签1', '标签2'],
       featured: false,
       status: 'active',        // 仅用于兜底展示
       requiresAuth: false,
       sortOrder: 10,
       isStatic: true
     }
     ```
   - 保持 `id`、`category`、`route` 与路由配置一致。

4. **在后台创建/同步记录**  
   - 进入 `/admin/tools/management`，使用“创建工具”按钮录入同 `id` 的工具，并设置分类、描述、排序、`requiresAuth` 等属性。  
   - 若已经存在同 `id` 的记录，直接编辑即可。后台数据会成为对外展示的唯一来源。

5. **验证与回归**  
   - 打开工具列表页面，触发 `toolsService.initialize()`（刷新即可），确认新工具展示。  
   - 在后台切换状态为“禁用/即将上线”，刷新前端列表确认工具隐藏。  
   - 若 API 暂时不可用，前端会回退到静态数据，保证关键工具仍然露出。

## 补充建议
- 对于必须永久显示的核心工具，可在后台保持 `status = active` 并开启 `featured`，前端推荐区即可自动出现。
- 如需手动种子数据库，可编写脚本调用 `/admin/tools` 接口或直接写入 MongoDB，内容与静态配置保持一致。
- 后续如果静态兜底逻辑需要关闭，可在 `mergeStaticTools` 中增加开关，部署时再按需启用。
