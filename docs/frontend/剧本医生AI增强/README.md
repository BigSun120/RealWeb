## 🎯 快速理解

### 核心理念
剧本医生采用**三阶段递进式诊断**，结合**快速诊断（本地规则）+ AI深度诊断（外部API）**双模式，为创作者提供从前期准备到完整剧本的全流程质量把控。

### 三大阶段

```
┌────────────────────────────────────────────────────┐
│ 阶段一：前期准备检查（当前重点）                   │
│ ├─ 世界观完整性                                    │
│ ├─ 角色设定质量                                    │
│ ├─ 角色关系图谱                                    │
│ └─ 剧情大纲结构                                    │
│ 目标：确保可以开始分集创作                         │
└────────────────────────────────────────────────────┘
              ↓ 通过门槛（≥75分）
┌────────────────────────────────────────────────────┐
│ 阶段二：分集质量检查（逐集优化）                   │
│ ├─ 单集结构完整性                                  │
│ ├─ Hook与悬念设计                                  │
│ ├─ 节奏与信息密度                                  │
│ └─ 台词质量评估                                    │
│ 目标：保证每一集质量稳定                           │
└────────────────────────────────────────────────────┘
              ↓ 完成≥80%分集
┌────────────────────────────────────────────────────┐
│ 阶段三：整体优化检查（全局视角）                   │
│ ├─ 剧情连贯性分析                                  │
│ ├─ 角色弧光完整性                                  │
│ ├─ 情感曲线评估                                    │
│ └─ 商业价值预测                                    │
│ 目标：提升整体可看性和市场竞争力                   │
└────────────────────────────────────────────────────┘
```

### 双诊断模式

| 模式 | 快速诊断（本地） | AI深度诊断 |
|------|----------------|-----------|
| **速度** | 2-5秒 | 30-60秒 |
| **成本** | 免费 | 消耗Token |
| **方式** | 规则引擎 | API调用 |
| **能力** | 基础检查、统计分析 | 逻辑分析、创意建议、市场预测 |
| **适用** | 日常检查、快速反馈 | 深度诊断、专业评估 |

## 🌟 核心特性

### 1. 阶段自适应
系统根据项目进度自动切换诊断重点：
- 前期准备阶段 → 聚焦基础设定
- 分集创作阶段 → 聚焦单集质量
- 整体优化阶段 → 聚焦全局协调

### 2. 双模式互补
- **快速诊断**：满足日常检查需求，零成本、秒出结果
- **AI诊断**：提供深度专业分析，包括逻辑评估、创意建议

### 3. 可操作建议
不仅指出问题，还提供：
- 优先级排序（严重 > 警告 > 提示）
- 可跳转定位（直接跳到问题模块）
- 具体优化方案（可直接执行）

### 4. 外部AI支持
支持生成结构化提示词，可用于：
- ChatGPT / Claude / 文心一言等外部AI
- 自定义诊断维度和重点
- 灵活控制成本

## 📊 指标体系概览

### 阶段一：前期准备（权重分配）
- **世界观完整性**：20% - 字段覆盖、内容充实、类型特征
- **角色设定质量**：25% - 数量配置、角色完整度、深度刻画
- **角色关系图谱**：25% - 覆盖度、张力指数、连通性
- **剧情大纲结构**：30% - 三幕均衡、节点质量、集数规划

**通过标准**：≥75分可开始分集创作

### 阶段二：分集质量（单集评分）
- **结构完整性**：30% - 场景设置、内容充实
- **Hook与悬念**：25% - 开篇抓人、结尾期待
- **节奏密度**：20% - 信息量、冲突频率
- **台词质量**：15% - 符合人设、推进剧情、金句
- **大纲一致性**：10% - 与规划匹配

**合格标准**：≥70分/集

### 阶段三：整体优化（全局评分）
- **剧情连贯性**：20% - 时间线、因果链、伏笔回收
- **角色弧光**：25% - 成长曲线、转变自然
- **情感曲线**：20% - 起伏节奏、高潮分布
- **节奏把控**：15% - 三幕节奏、信息密度
- **商业价值**：20% - 爆款要素、市场匹配

**优秀标准**：≥85分

## 📝 使用场景

### 场景1：新项目创建后
**用户**：刚完成世界观和角色设定  
**操作**：点击"快速诊断"  
**结果**：发现角色关系覆盖不足，主角缺少对立关系  
**行动**：在关系图谱中补充竞争和冲突关系

### 场景2：大纲完成，准备分集
**用户**：完成三幕大纲，共15个节点  
**操作**：点击"AI深度诊断"  
**结果**：AI指出第二幕节奏拖沓，建议压缩并增加2个转折点  
**行动**：调整大纲结构，优化节点分布

### 场景3：分集创作中期
**用户**：完成了前20集  
**操作**：选择"批量检查(11-20集)"  
**结果**：发现第15-18集缺少情感高潮，结尾悬念强度偏低  
**行动**：修改第17集结尾，增加一个反转

### 场景4：全剧完成前
**用户**：完成了全部60集  
**操作**：点击"整体优化诊断"  
**结果**：情感曲线显示第30-40集过于平淡，建议增强中段冲突  
**行动**：回头优化第35-38集的冲突设计
