# 短剧题材智能筛选助手

## 背景说明
我想创作一部短剧（60-100集，每集2-3分钟），但还没有明确的方向。请你作为专业的短剧策划顾问，帮我系统化地筛选和评估题材。

---

## 第一步：了解我的创作偏好

请先询问我以下问题（如果我没有明确偏好，可以跳过）：

1. **目标受众**：你希望吸引哪类观众？（如：18-25岁女性、30+职场人士、泛大众等）
2. **情感倾向**：你更倾向什么情感基调？（如：甜宠、虐恋、爽文、悬疑、励志等）
3. **题材禁区**：有没有不想碰的题材类型？（如：校园、古装、都市等）
4. **创作资源**：拍摄预算和场景限制？（如：低成本/中等/充足，室内为主/可外景）
5. **个人优势**：你擅长写什么类型的故事？（如：情感细腻、剧情反转、幽默对白等）

---

## 第二步：生成6个题材方向

基于我的回答（或通用热门趋势），请为我生成**6个不同类型**的短剧题材方向，每个方向包含：

### 格式要求：
```
【题材方向X】名称
- **类型标签**：（如：都市爽文、古装甜宠、悬疑反转等）
- **一句话概念**：用一句话概括核心卖点
- **故事梗概**：（100-150字）简述主线剧情和核心冲突
- **目标受众**：最适合的观众群体
- **差异化亮点**：与同类题材的3个差异点
```

**要求**：
- 6个方向需要覆盖不同类型（至少包含：爽文类、情感类、悬疑/反转类）
- 每个方向都要有明确的"爆点"设计
- 考虑当前短剧市场趋势（2024-2025）

---

## 第三步：多维度评分体系

对每个题材方向进行**8个维度**的评分（满分10分），并给出评分理由：

### 评分维度：

| 维度 | 评分标准 |
|------|---------|
| **1. 市场热度** | 当前观众对该题材的关注度和需求量 |
| **2. 差异化程度** | 与现有爆款的差异性，避免同质化 |
| **3. 情感共鸣** | 能否触动观众内心，引发强烈情感反应 |
| **4. 爽点密度** | 剧情节奏和高潮设计，能否持续抓住观众 |
| **5. 制作难度** | 拍摄成本、场景要求、演员要求的复杂度（分数越高=越简单） |
| **6. 商业价值** | 广告植入空间、IP延展性、变现潜力 |
| **7. 传播潜力** | 话题性、短视频切片价值、社交媒体讨论度 |
| **8. 创新性** | 题材/叙事/人设的创新突破点 |

```

   理由：（具体说明差异点）

   理由：（说明情感触点）

4️⃣ 爽点密度：★★★★★★★☆☆☆ (7/10)
```

## ⚠️ 重要约束

1. **所有评分必须客观**，不要一味给高分，要真实反映题材的优劣势
2. **理由必须具体**，避免空洞表述，要有数据或案例支撑
3. **差异化分析必须深入**，明确指出与现有爆款的3个以上不同点
4. **风险提示必须真实**，诚实告知可能遇到的问题
5. **推荐排名要有依据**，不仅看综合分，还要考虑创作者的实际情况
