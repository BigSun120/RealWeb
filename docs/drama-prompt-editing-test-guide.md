# 提示词编辑功能 - 手动测试指南

## 测试环境
- **前端服务**: http://localhost:3001/
- **测试页面**: `/tools/productivity/drama` (短剧脚本生成工具)
- **测试组件**: PromptDialog (提示词对话框)

## 测试前准备

### 1. 启动服务
```bash
# 启动前端开发服务器
npm run dev --prefix "E:\AI\mycode\RealWeb\frontend"

# 启动后端服务器（另一个终端）
npm start --prefix "E:\AI\mycode\RealWeb\backend"
```

### 2. 打开浏览器
访问: http://localhost:3001/tools/productivity/drama

### 3. 选择或创建项目
- 从列表中选择一个现有项目，或
- 创建一个新项目进行测试

## 测试场景

### 场景1: 世界观提示词编辑

#### 步骤:
1. 在工作台页面，找到"世界观设定"卡片
2. 填写世界观表单:
   - 故事背景: "现代都市"
   - 世界主题: "职场奋斗与爱情"
   - 核心冲突: "事业与爱情的选择"
   - 情感基调: 选择"温馨感人"或自定义
3. 点击"生成提示词"按钮

#### 预期结果:
✅ 打开提示词对话框，显示生成的提示词内容

#### 测试编辑功能:
1. **查看模式检查**:
   - ✅ 提示词以预格式化文本(pre)显示
   - ✅ 右上角显示"编辑"按钮
   - ✅ 显示字符计数标签（如"1234 字符"）

2. **切换到编辑模式**:
   - 点击"编辑"按钮
   - ✅ "编辑"按钮变为"完成"按钮（绿色/主题色）
   - ✅ 提示词内容变为可编辑的文本框（textarea）
   - ✅ 文本框内容与原始提示词一致

3. **编辑内容**:
   - 修改提示词内容，例如添加一段文字："请特别关注人物内心冲突的描写"
   - ✅ 字符计数实时更新
   - ✅ 文本框支持多行编辑
   - ✅ 滚动条正常工作（内容较长时）

4. **完成编辑**:
   - 点击"完成"按钮
   - ✅ 显示"编辑完成"的成功提示消息
   - ✅ 切换回查看模式（pre显示）
   - ✅ 显示编辑后的内容

5. **复制编辑后的内容**:
   - 点击"复制提示词"按钮
   - ✅ 显示"提示词已复制到剪贴板"的成功提示
   - 粘贴到文本编辑器中
   - ✅ 粘贴的内容是编辑后的版本（包含新添加的文字）

6. **关闭对话框**:
   - 点击"关闭"按钮
   - ✅ 对话框关闭

7. **重新打开**:
   - 再次点击"生成提示词"按钮
   - ✅ 对话框显示原始生成的提示词（未保存之前的编辑）

### 场景2: 角色提示词编辑

#### 步骤:
1. 在工作台页面，找到"角色管理"卡片
2. 点击"添加角色"按钮，填写角色信息:
   - 角色名称: "林心怡"
   - 年龄: "28"
   - 性别: "女"
   - 职业: "设计师"
   - 性格特点: "独立自信、追求完美"
   - 背景故事: "从小城市奋斗到大城市的职场新秀"
3. 保存角色
4. 在角色卡片上，点击"生成提示词"按钮

#### 预期结果:
✅ 打开提示词对话框，显示角色相关的提示词

#### 测试编辑功能:
1. 点击"编辑"按钮
2. 在提示词中添加角色关系描述: "与男主角是同事关系，互相暗恋但未表白"
3. 点击"完成"按钮
4. ✅ 确认编辑成功保存
5. 点击"复制提示词"
6. ✅ 确认复制的内容包含新添加的关系描述

### 场景3: 边界测试

#### 测试3.1: 空内容编辑
1. 生成提示词后，点击"编辑"
2. 删除所有内容（留空）
3. 点击"完成"
4. ✅ 不应该报错，字符计数显示"0 字符"
5. 点击"复制提示词"
6. ✅ 不应该报错，提示复制成功

#### 测试3.2: 长文本编辑
1. 生成提示词后，点击"编辑"
2. 粘贴一段很长的文本（如3000+字符）
3. ✅ 文本框应该有滚动条
4. ✅ 字符计数正确显示（如"3247 字符"）
5. 滚动查看内容
6. ✅ 滚动条样式美观（自定义滚动条）
7. 点击"完成"，然后"复制提示词"
8. ✅ 长文本能正确复制

#### 测试3.3: 编辑过程中关闭
1. 生成提示词后，点击"编辑"
2. 修改部分内容（不点击"完成"）
3. 直接点击"关闭"按钮
4. ✅ 对话框关闭
5. 重新打开提示词对话框
6. ✅ 显示原始内容（未保存的编辑被丢弃）

#### 测试3.4: 特殊字符处理
1. 生成提示词后，点击"编辑"
2. 添加特殊字符: 
   - 换行符（多行文本）
   - 中文标点：【】《》、，。！？
   - 表情符号：😊 🎭 📝
   - 英文标点："" '' () []
3. 点击"完成"
4. ✅ 所有字符正确显示
5. 点击"复制提示词"
6. 粘贴到文本编辑器
7. ✅ 所有特殊字符正确复制

### 场景4: 响应式测试

#### 步骤:
1. 打开浏览器开发者工具
2. 切换到移动设备模式（如iPhone 12）
3. 生成并打开提示词对话框
4. ✅ 对话框宽度适配移动屏幕
5. 点击"编辑"
6. ✅ 文本框高度适配（移动端应该较小，约300px）
7. ✅ 按钮大小合适，易于点击
8. ✅ 字符计数标签不换行或正确换行
