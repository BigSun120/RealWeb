## 数据流程图

```
用户操作
   ↓
OutlineEditor / EpisodeManager (组件内部处理 UI 交互)
   ↓
emit('save', data) - 触发保存事件
   ↓
workbench.vue (handleSaveOutline / handleSaveEpisodes)
   ↓
updateDramaProject() - 调用后端 API
   ↓
后端 Controller → 更新 MongoDB
   ↓
返回响应 → 更新前端本地状态
```

## 常见问题排查

### 问题 1: 保存失败
**症状**: 点击保存后没有成功提示  
**排查步骤**:
1. 打开浏览器开发者工具（F12）
2. 查看 Network 标签中的 API 请求
3. 检查请求状态码和响应内容
4. 查看 Console 中是否有错误信息

**可能原因**:
- 后端服务未启动
- API 路径错误
- 数据格式不匹配
- 身份验证失败

### 问题 2: 数据刷新后丢失
**症状**: 刷新页面后数据消失  
**排查步骤**:
1. 检查保存是否成功（查看 Network 请求）
2. 检查 `onMounted` 中的数据加载逻辑
3. 验证后端数据库中是否有数据

**可能原因**:
- 保存失败但未显示错误
- 数据加载逻辑错误
- 数据库连接问题

### 问题 3: 角色下拉列表为空
**症状**: 在大纲编辑器中选择角色时，下拉列表为空  
**排查步骤**:
1. 确认已在「角色管理」中添加角色
2. 确认角色已保存成功
3. 检查 `availableCharacters` 计算属性

**可能原因**:
- 未添加角色
- 角色未保存
- Props 传递错误

### 问题 4: 提示词生成失败
**症状**: 点击生成提示词后报错  
**排查步骤**:
1. 检查 Console 中的错误信息
2. 确认 `utils/promptTemplates.js` 文件存在
3. 验证函数导入路径

**可能原因**:
- 提示词模板文件缺失
- 导入路径错误
- 数据格式不符合预期
