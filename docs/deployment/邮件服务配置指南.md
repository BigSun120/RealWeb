## 📊 当前邮件系统架构

### 邮件服务分工

```
注册验证邮件流程：
用户注册 → 后端EmailService → Postfix(localhost:25) → 用户真实邮箱

临时邮箱服务流程：
外部邮件 → Postfix(端口25) → 虚拟域名转发 → Inbucket(端口2500)
```

### Postfix 配置

```bash
# 本地域名（用于系统邮件）
mydestination = mail.godaug.fun, localhost.godaug.fun, localhost

# 虚拟域名（转发到临时邮箱）
virtual_mailbox_domains = godaug.fun
virtual_transport = smtp:[127.0.0.1]:2500
```

### 服务状态

- ✅ **Postfix**：端口 25，处理邮件发送和接收
- ✅ **Inbucket**：端口 2500(SMTP) + 9000(Web)，临时邮箱服务
- ✅ **后端 API**：端口 8000，邮件服务接口

## 🔧 备用配置选项（如需扩展）

### 选项 1：QQ 邮箱 SMTP（推荐，免费）

#### 1.1 获取 QQ 邮箱授权码

1. 登录 QQ 邮箱 (mail.qq.com)
2. 点击"设置" → "账户"
3. 找到"POP3/IMAP/SMTP/Exchange/CardDAV/CalDAV 服务"
4. 开启"IMAP/SMTP 服务"
5. 按提示发送短信，获取**授权码**（不是登录密码！）

#### 1.2 更新配置文件

编辑 `ecosystem.config.js`：

```javascript
SMTP_HOST: 'smtp.qq.com',
SMTP_PORT: 587,
SMTP_SECURE: false,
SMTP_AUTH: true,
SMTP_USER: 'your-qq-email@qq.com',        // 替换为你的QQ邮箱
SMTP_PASS: 'your-authorization-code',      // 替换为授权码
EMAIL_FROM: 'your-qq-email@qq.com',       // 替换为你的QQ邮箱
```

### 选项 2：Gmail SMTP（国外用户推荐）

#### 2.1 开启 Gmail 应用专用密码

1. 登录 Google 账户
2. 开启两步验证
3. 生成应用专用密码

#### 2.2 配置

```javascript
SMTP_HOST: 'smtp.gmail.com',
SMTP_PORT: 587,
SMTP_SECURE: false,
SMTP_AUTH: true,
SMTP_USER: 'your-email@gmail.com',
SMTP_PASS: 'your-app-password',
EMAIL_FROM: 'your-email@gmail.com',
```

### 选项 3：163 邮箱 SMTP

#### 3.1 开启 SMTP 服务

1. 登录 163 邮箱
2. 设置 → POP3/SMTP/IMAP
3. 开启 SMTP 服务，获取授权码

#### 3.2 配置

```javascript
SMTP_HOST: 'smtp.163.com',
SMTP_PORT: 587,
SMTP_SECURE: false,
SMTP_AUTH: true,
SMTP_USER: 'your-email@163.com',
SMTP_PASS: 'your-authorization-code',
EMAIL_FROM: 'your-email@163.com',
```

##  故障排除

### 常见问题

#### 1. 授权码错误

- 确保使用的是授权码，不是登录密码
- 重新生成授权码

#### 2. 连接被拒绝

- 检查 SMTP 服务器地址和端口
- 确认邮箱服务商的 SMTP 设置

#### 3. 邮件被拦截

- 检查垃圾邮件文件夹
- 添加发件人到白名单
